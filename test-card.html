设计特点

✓ 规范尺寸：260px × 88px，符合设计规范

✓ 信息层级：顶部车头（车次+区间+股道方向）→ 中部时间 → 底部作业状态

✓ 未来科技感：玻璃态背景、渐变边框、发光效果、精细阴影

✓ 浅色模式：柔和配色，不刺眼，高对比度易读

✓ 紧凑布局：充分利用空间，拒绝大面积留白

✓ 交互反馈：选中态（停站类型色）、关联态（绿色）、悬停态（上浮）

✓ 作业状态：底部4色条显示检票/站台/出站/上水的实时状态

✓ 晚点提示：红色徽章显示延误分钟数
