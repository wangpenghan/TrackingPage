# 车站客运模板抽屉布局优化设计

## 背景
站点“车站客运模板”页面的编辑抽屉在客运模式下存在以下问题：
- 抽屉底部留白过大，视觉上显得空旷。
- “上水作业”“吸污作业”按钮在狭窄宽度下换行，影响观感。
- “编组维护”字段排列为三列且纵向间距较大，信息密度偏低。
- 非客运模式标题中使用警示图标，但缺少说明。

## 目标
- 保持抽屉单列结构的同时提升信息密度，减少空白。
- 将“编组维护”区域调整为两列布局并保证字段对齐。
- 解决作业标签换行问题，维持紧凑的一行展示。
- 为非客运模式标题的警示图标补充说明，提升可理解性。

## 范围
- 仅涉及 `EditDrawer` 组件的客运模式布局及样式调整。
- 非客运模式保留现有结构，仅在整体 padding 上做轻微收敛。
- 不改动数据结构、校验逻辑或同步逻辑。

## 设计方案（方案A）
### 抽屉层级
- 客运模式抽屉改为 `max-w-[960px]`，统一 `p-2` 作为内部 padding。
- 底部 padding 调整为 `pb-3`，减少尾部空白。
- 标题区按钮组间距收紧，保持 `flex` 对齐不变。

### 基础信息区
- 栅格维持两列，但 gap 调整为 `gap-1.5`，输入控件高度统一为 `h-7`。
- 车次号输入框保留高亮边框，仅缩减 padding，保证聚焦视觉。

### 编组配置区
- 区块内采用 `grid grid-cols-2 gap-x-2 gap-y-1`。
- 字段按业务优先级左右分布，所有选择器 / 输入框高度统一 `h-7`。
- 上水/吸污按钮放置在底部独立一行，父容器使用 `flex gap-2`。
- 每个按钮内部 `justify-between`，文案 `whitespace-nowrap`，状态徽章最小宽度 `min-w-[48px]`，避免换行。

### 作业标签
- 客运/非客运模式统一使用 `flex items-center gap-2 justify-between` 布局。
- 勾选框与文案始终同一行，状态徽章字体 `text-[11px]`。

### 运行规律与其他区
- 调整字段间距至 `gap-1.5`，控件高度 `h-6`，使信息密度与上方表单一致。
- 非客运模式在卡片底部增加 `pb-2`，确保上下留白一致。

### 警示图标
- 非客运模式标题保留 `⚠️`，统一使用 `text-[#D97706]`。
- 添加 tooltip 文案“非客运模板：仅显示作业配置字段”。

## 验收标准
1. 客运模式抽屉宽度和底部空白明显收紧，无滚动条异常。
2. “编组配置”字段两列整齐对齐，所有控件高度一致。
3. 上水/吸污两个选项在任何宽度下均不换行，状态徽章宽度固定。
4. 非客运模式标题悬停时出现提示文案。
5. 切换客运/非客运模式后表单布局稳定，无跳动。

## 风险与对策
- **风险**：布局收紧可能影响极端数据的可读性。
  - **对策**：保持控件最小宽度，必要时允许文本溢出省略显示。
- **风险**：Tooltip 组件若不存在需自行实现。
  - **对策**：优先复用现有样式工具类，如无则使用纯 CSS 构建简易提示。
