## 1. P0 改进方案（关键，必须实现）

### 1.1 修复右侧侧栏结构（行 700-791）

**问题**：`w-72` 侧栏被错误地嵌套在主区域 `flex-1 overflow-y-auto space-y-1.5` 内部底部，导致：
- 侧栏显示在表格行底部而不是固定右侧
- 用户无法同时查看表格和侧栏
- 布局破坏

**当前代码结构**：
```tsx
<div className="flex flex-1 overflow-hidden">
  <div className="flex-1 overflow-y-auto p-1.5 space-y-1.5">
    {/* 行1、行2、行3... */}
    
    {/* ❌ 错误：侧栏在这里 */}
    <div className="w-72 overflow-y-auto border-l ...">
      {/* 侧栏内容 */}
    </div>
  </div>
</div>
```

**改进后结构**：
```tsx
<div className="flex flex-1 overflow-hidden">
  {/* 左侧主区域 */}
  <div className="flex-1 overflow-y-auto p-1.5 space-y-1.5">
    {/* 行1、行2、行3... */}
  </div>
  
  {/* ✅ 正确：侧栏与主区并列 */}
  <div className="w-[240px] overflow-y-auto border-l border-[#E5E7EB] bg-white flex-shrink-0">
    {/* 侧栏内容 */}
  </div>
</div>
```

**实现步骤**：
1. 找到当前侧栏的开始位置（行 700 左右）
2. 将侧栏整个 div 块**剪切**出来
3. 粘贴到外层 `<div className="flex flex-1 overflow-hidden">` 的**第二个子元素**（主区域之后）
4. 修改侧栏 className：`w-72` → `w-[240px]`，添加 `flex-shrink-0`
5. 验证：主区域和侧栏应该在同一行显示，侧栏不再在主区底部

**验收标准**：
- [ ] 侧栏显示在主区域右侧，宽度 240px
- [ ] 侧栏与主区域为 flex 兄弟元素，不嵌套
- [ ] 滚动主区时，侧栏固定不动
- [ ] 非客运模式（无侧栏）正常显示

### 1.2 客运模式：重组第1行布局（行 305-503）

**问题**：第1行显示"车次信息 + 列车信息"，但规范要求"车次信息 + 时间&空间"，导致：
- 到达/发车时间没有专属输入区域
- 列车信息过长，右侧无法展示时间/空间配置
- 第2行检票时间右侧留白

**当前第1行结构**：
```tsx
<div className="flex gap-2">
  <div className="flex-1">
    {/* 车次信息 */}
    车次号、列车类型、始发站、终到站、到达车次、始发车次、接续车次
  </div>
  <div className="flex-1">
    {/* ❌ 列车信息（应该移到第2行） */}
    车型、编组、编组方向、地标颜色、担当局、列车等级、列车车底
  </div>
</div>
```

**应为第1行结构**：
```tsx
<div className="flex gap-2">
  <div className="flex-1">
    {/* 车次信息（保持不变） */}
    车次号、列车类型、始发站、终到站、到达车次、始发车次、接续车次
  </div>
  <div className="flex-1">
    {/* ✅ 时间 & 空间（新增） */}
    <div className="text-[12px] font-bold text-[#D97706] bg-[#FEF3C7] px-1.5 py-0.5 rounded mb-2">时间 & 空间</div>
    {/* 时间行 */}
    <div className="grid grid-cols-2 gap-2 mb-2">
      <div>到达时间</div>  {/* 从其他地方移来 */}
      <div>发车时间</div>  {/* 从其他地方移来 */}
    </div>
    {/* 空间行 */}
    <div className="grid grid-cols-3 gap-2">
      <div>股道</div>      {/* 从侧栏移来 */}
      <div>站台</div>      {/* 从侧栏移来 */}
      <div>停车位</div>    {/* 从侧栏/列车信息移来 */}
    </div>
  </div>
</div>
```

**实现步骤**：
1. 定位当前第1行右侧「列车信息」区块（行 405-503 左右）
2. 新建「时间 & 空间」区块，复制到第1行右侧（替换列车信息）
3. 包含字段：
   - **时间行**：`arrivalTime`、`departureTime`
   - **空间行**：`track`、`platform`、`parkingSpot`
   - **方向行**（可选）：`entryDirection`、`exitDirection`
4. 将「列车信息」区块移至第2行

**验收标准**：
- [ ] 第1行右侧显示"时间 & 空间"标题
- [ ] 时间行包含到达/发车时间输入框
- [ ] 空间行包含股道、站台、停车位选择框
- [ ] 第1行两栏高度接近，布局均衡

### 1.3 客运模式：重组第2行布局（行 505-648）

**问题**：第2行只有「列车信息」和「检票时间」两个区块，但检票时间只占 `w-1/2`，右侧空白浪费

**当前第2行结构**：
```tsx

  <div className="w-1/2">
    {/* ❌ 检票时间占左半 */}
  </div>
  {/* 右侧空白 */}
</div>
```

**应为第2行结构**：
```tsx
<div className="flex gap-2">
  <div className="flex-1">
    {/* ✅ 列车信息（从第1行移来） */}
    车型、编组、编组方向、地标颜色、担当局、列车等级、列车车底
  </div>
  <div className="flex-1">
    {/* ✅ 检票时间（与列车信息并排） */}
    进站开检、进站停检、出站开检、出站停检
  </div>
</div>
```

**实现步骤**：
1. 从第1行剪切「列车信息」区块
2. 粘贴为第2行左侧，改为 `flex-1`（原 `w-1/2` 改为 `flex-1`）
3. 修改检票时间右侧的 className：`w-1/2` → `flex-1`
4. 两个区块都应该用 `flex-1` 平均分配空间

**验收标准**：
- [ ] 第2行显示「列车信息」和「检票时间」两个区块
- [ ] 两个区块宽度相等（都是 flex-1）
- [ ] 第2行右侧无空白
- [ ] 布局高度均衡

### 1.4 非客运模式：移除冗余字段

**问题**：以下字段在非客运模式中无意义，但仍然显示：
- `connectingTrain`（接续车次）
- `entryDirection`（进站方向）
- `landmarkColor`（地标颜色）
- `carriages`（列车车底）

**移除方式**：对每个字段的渲染位置添加条件：`{!isFreightMode && ( ... )}`

**具体位置与修复**：

#### 接续车次字段
查找：`connectingTrain` 或"接续车次"  
添加条件：
```tsx
{!isFreightMode && (
  <div>
    <label>接续车次</label>
    {/* 输入框 */}
  </div>
)}
```

#### 进站方向字段
查找：`entryDirection` 或"进站方向"  
添加条件：
```tsx
{!isFreightMode && (
  <div>
    <label>进站方向</label>
    {/* 选择框 */}
  </div>
)}
```

#### 地标颜色字段
查找：`landmarkColor` 或"地标颜色"  
添加条件：
```tsx
{!isFreightMode && (
  <div>
    <label>地标颜色</label>
    {/* 显示框 */}
  </div>
)}
```

#### 列车车底字段
查找：`carriages` 或"列车车底"  
添加条件：
```tsx
{!isFreightMode && (
  <div>
    <label>列车车底</label>
    {/* 输入框 */}
  </div>
)}
```

**验收标准**：
- [ ] 非客运模式中不显示接续车次
- [ ] 非客运模式中不显示进站方向
- [ ] 非客运模式中不显示地标颜色
- [ ] 非客运模式中不显示列车车底
- [ ] 客运模式仍然显示这些字段

## 2. P1 改进方案（重要，应优化）

### 2.1 右侧侧栏宽度调整

**当前**：`w-72` = 288px

**改为**：`w-[240px]` = 240px

**位置**：修复后的侧栏 div（见 1.1 方案）

**实现**：
```tsx
// 改前
<div className="w-72 overflow-y-auto border-l ...">

// 改后
<div className="w-[240px] overflow-y-auto border-l ...">
```

**理由**：
- 240px 是标准侧栏宽度，与设计规范一致
- 为主区域腾出更多空间
- 在 1366px（laptop 最小宽度）下：主区 1106px（充足）+ 侧栏 240px（标准）

**验收标准**：
- [ ] 侧栏宽度调整为 240px
- [ ] 在不同屏幕尺寸下响应式表现正常
- [ ] 内容不被截断

---

### 2.2 非客运模式高度优化

**当前问题**：移除冗余字段后，页面可能出现过度留白

**优化方向**：
1. 检查区块间 gap/padding，确保紧凑但舒适
2. 移除或减小不必要的顶部/底部外边距
3. 确保「运行规律」区块底部没有过度空白

**建议调整**：
- 区块间 `gap-2` 改为 `gap-1.5` 或保持（根据视觉效果）
- 区块内部 padding 改为 `p-1.5`（原 `p-2`）
- 取消「运行规律」下方多余的 margin

**验收标准**：
- [ ] 非客运模式高度合理，不过度留白
- [ ] 所有区块内容清晰可读
- [ ] 无明显视觉不均衡
