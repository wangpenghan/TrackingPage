# 计划比对页面重设计方案

**版本：** v2.0  
**日期：** 2026-05-08  
**适用模块：** 盯控页面 / 计划比对 / 页面重构

---

## 1. 现状问题分析

### 1.1 布局不符合用户操作流程

当前页面采用传统**数据浏览布局**（表格+侧边栏），但计划比对实际上是一个**顺序工作流**，用户每次使用这个页面的目的是：
1. 理解今日vs明日的差异全貌
2. 逐一核对每条变更
3. 做出决策（锁定/同步更新）

**问题**：页面没有明确的流程导航，用户容易迷失工作进度。

### 1.2 时间段分类不符合业务

**预览面板底部的"早班/午班/晚班"筛选**：
- 没有实际业务需求（用户是全天核对，不按班次）
- 占用了宝贵的面板底部空间
- 应完全移除

### 1.3 样式与客运模板不一致

当前计划比对使用 `pc-` 前缀的 CSS 类，而客运模板直接用 Tailwind CSS。需要统一风格。

### 1.4 其他问题

| 问题 | 影响 |
| :--- | :--- |
| 差异汇总占用整个 toolbar | toolbar 被压扁，操作按钮挤在一起 |
| 没有明确的"开始"和"完成"标记 | 用户不知道还有多少工作 |
| 侧边预览片段信息有限 | 需要点击查看详情，操作繁琐 |
| 操作按钮（全部解锁/同步更新）位置不明确 | 不知道何时该做这些操作 |

## 2. 新布局设计方案

### 2.1 设计理念

采用**工作流导向布局**：
- **顶部**：步骤指示器 + 快速信息
- **中部**：主工作区（表格核对）
- **右侧**：详情与快速操作面板
- **底部**：决策按钮（明确的"完成"操作）

### 2.3 关键区块详细设计

#### 区块 A：步骤指示器

```
目的：引导用户理解当前工作在哪个阶段

设计：
┌────────────────────────────────────────┐
│ 🎯 工作流程                            │
│ ┌──────┐     ┌──────┐     ┌──────┐   │
│ │ ✓ 1  │  →  │ 2  ○ │  →  │ 3  ○ │  │
│ │了解  │     │核对  │     │确认  │  │
│ │变更  │     │差异  │     │锁定  │  │
│ └──────┘     └──────┘     └──────┘   │
│              (当前步骤)                 │
└────────────────────────────────────────┘
```

**样式**：Tailwind 风格，圆形步骤指示 + 连接线

#### 区块 B：差异汇总（卡片化）

```
替代当前的 toolbar 差异徽章。采用**可展开的卡片设计**：

┌──────────────────────────────────────────┐
│ 差异汇总                                 │
├──────────────────────────────────────────┤
│ ┌─────────────┐ ┌─────────────┐         │
│ │ 新增 3 条   │ │ 减少 1 条   │         │
│ │ [展开 ↓]   │ │ [展开 ↓]   │         │
│ └─────────────┘ └─────────────┘         │
│ ┌─────────────┐ ┌─────────────┐         │
│ │ 变更 5 条   │ │ 无变化 15 条│         │
│ │ [展开 ↓]   │ │             │         │
│ └─────────────┘ └─────────────┘         │
│                                          │
│ 💡 所有项目已包含，可逐一核对             │
└──────────────────────────────────────────┘
```

**功能**：
- 点击卡片可展开/收起该类型的列表
- 背景色对应差异类型（绿/红/蓝/灰）
- 不替代表格过滤，只作为快速统计

#### 区块 C：主表格（保留，优化）

```
保留当前表格结构，但优化：

1. 默认按 departureTime 排序（用户习惯：下午3点查看，应按时间流）
2. 移除"早班/午班/晚班"过滤（完全删除）
3. 增加右侧操作面板，选中行时实时显示详情
4. 提升"核对"列的优先级（与当前等同）
5. 表格底部显示进度条（当前在上方）
```

## 5. 样式统一（Tailwind 迁移）

### 5.1 保留但优化的 CSS

部分功能可保留 `pc-` 前缀的 CSS，但统一方向：

```css
/* 逐步替换为 Tailwind */
.pc-table-row ← bg-white hover:bg-gray-50 border-l-4 border-transparent
.pc-btn-primary ← bg-[#5e6ad2] hover:bg-[#4f5cbd] text-white
.pc-modal-overlay ← fixed inset-0 bg-black/35 flex items-center justify-center
```

## 6. 核心改变总结

| 维度 | 当前 | 优化后 |
| :--- | :--- | :--- |
| **布局** | 表格 + 右侧预览 | 工作流导向（顶部步骤 → 中部表格 → 右侧详情 → 底部决策） |
| **时间段筛选** | 有（早班/午班/晚班） | 无（完全移除） |
| **差异汇总** | Toolbar 中的徽章 | 顶部卡片式，可展开 |
| **操作按钮位置** | Toolbar（混乱） | 底部决策区（明确） |
| **详情显示** | 点击表格行弹窗 | 右侧实时面板 |
| **用户引导** | 无 | 步骤指示器 + 进度提示 + 底部说明 |
| **样式** | 混合 CSS + Tailwind | 统一 Tailwind |
