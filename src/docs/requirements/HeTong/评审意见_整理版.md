# 铁路客运综合交通枢纽大客流智能疏导与接驳交通协同优化技术研究
## 项目方案评审意见

2026年4月15日，电子所机电装备及系统事业部主持召开了"铁路客运综合交通枢纽大客流智能疏导与接驳交通协同优化技术研究"项目方案评审会。审查组认真听取了项目的总体技术方案、研究内容等汇报。经认真讨论，形成评审意见如下：

1、项目方案以枢纽大客流安全高效出行为出发点，对当前存在的问题进行了深入分析，提出了基于视频多模态感知的客流实时监测与短时预测、复杂场景下大客流动态疏导路径规划与设备协同调度、铁路-地铁-公交-出租多制式运力协同优化等研究内容；论证了项目研究的必要性，明确了系统研制的目标，符合枢纽的实际建设需要，抓住了枢纽大客流疏导的业务痛点，能够为实现枢纽"内畅外联"、保障旅客高效安全出行提供理论和技术支持；项目充分考虑了系统的兼容性和扩展性，技术路线清晰，研究内容安排合理，满足后续迭代升级的需求。

2、总体方案对六项主要研究内容和三项关键技术进行了较为详细的规划，明确了各研究阶段的重点任务，提出了系统原型研制与试验验证的具体安排，方案可行。

3、项目方案研究内容充实，逻辑清晰，覆盖从需求分析到系统原型研制整个流程，进度安排合理，考核目标明确。研究组以实际需求为导向，针对大客流场景下旅客疏散效率低、接驳运力不匹配等突出问题，开展关键技术攻关，预期研究成果能够有效提升枢纽通行效率与接驳换乘效率。

审查组一致同意通过项目方案评审。建议在项目研发中进一步结合现场实际运营需求，深化算法模型的鲁棒性研究，完善关键技术的试验验证，为项目成果的实际应用切实打好基础。

## 立项评审意见

2026年4月15日，机电装备及系统事业部组织召开了"铁路客运综合交通枢纽大客流智能疏导与接驳交通协同优化技术研究"项目的立项评审会。专家组（名单附后）认真审阅了相关材料并听取了项目组关于方案的汇报，经质询和讨论，形成如下评审意见：

2. 项目建议书对视频多模态感知、动态路径规划、多制式运力协同等关键技术的研究进行了合理规划，并兼顾考虑了信创合规和按需弹性伸缩部署的要求，技术先进可行。

3. 项目建议书结构清晰、内容完整、技术针对性强，符合总体要求，可有效指导项目方案设计及后续功能研发。

专家组同意项目立项通过评审。

## 项目内容概述

为全面提升铁路客运综合交通枢纽大客流运行效率与接驳换乘能力，破解节假日高峰期大客流疏导不及时、接驳运力调度不同步等问题，突破传统人工经验管理模式，融合多源数据感知与智能决策技术，研究大客流智能疏导与接驳交通协同优化技术，实现客流实时监测、风险预警、路径诱导、设备联动及运力协同一体化。为适应枢纽智能化运营的新需求、新挑战，需对传统管理模式进行技术升级和方法创新，进一步推进枢纽客流管理智能化，有效提升枢纽通行效率，保障旅客出行安全，持续挖潜综合交通枢纽的整体运行效益，不断提高安全和运营管理水平，拓展枢纽服务范围、增强旅客出行体验。
