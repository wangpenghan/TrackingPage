# 代管列车盯控页面

## 📋 业务与功能

### 1.1 核心目标
> 简要说明该元素/页面的核心定位、解决的问题、用户价值

代管列车盯控页面是一个实时监控列车运行状态的可视化界面，旨在帮助铁路调度人员快速掌握列车到发时间、股道占用情况及运行状态，提高调度效率和决策准确性。

### 1.2 功能清单
> 列出所有功能模块及其优先级

- **时间轴显示**：展示当前时间和时间窗口，方便用户了解时间流逝和列车运行时间点。
- **面板布局**：按车站或区域分组显示列车信息，每个面板固定显示2行（上行/下行）。
- **列车卡片**：展示车次号、到发时间、股道、运行状态等关键信息。
- **连线功能**：显示列车在不同面板之间的接续关系，包括同车次号和显式接续两种类型。
- **交互功能**：支持点击列车卡片查看详情，悬停时卡片高亮显示。
- **状态标识**：通过颜色和标签标识列车的早/晚/正常状态。
- **分组背景**：为同一车次的多辆列车显示分组背景，增强视觉关联性。

### 1.3 交互要点
> 关键的交互触发点、反馈机制、状态变化

- **点击列车卡片**：触发详情查看，高亮显示选中的列车及其相关连线。
- **悬停卡片**：卡片轻微上浮，显示阴影效果，提升视觉层级。
- **时间轴拖拽**：支持拖拽时间轴调整时间窗口，查看不同时间段的列车运行情况。
- **状态变化**：列车状态变更时，卡片边框颜色和状态标签会相应变化。
