# 客运模板编辑抽屉重设计方案

> 文档类型：UI 重设计规格  
> 创建日期：2026-06-01  
> 关联原型：`src/prototypes/station-passenger-template/components/EditDrawer.tsx`  
> 适用范围：仅客运模式（`!isFreightMode`），非客运模式不受影响

---

## 一、现状问题

### 1.1 布局结构

当前客运模式抽屉宽度 1040px，采用**左侧主区 + 右侧 240px 固定侧栏**结构：

```
┌─────────────────────────────────────────────────────────────────┐
│  左侧主区（~800px）                    │  右侧侧栏（240px）       │
│  ┌──────────┬──────────┐              │  股道 / 站台             │
│  │ 车次信息  │ 列车信息  │              │  检票口（24个复选框）    │
│  └──────────┴──────────┘              │  候车室                  │
│  ┌──────────┬──────────┐              │  出站口                  │
│  │ 检票时间  │ 其他信息  │              │                          │
│  └──────────┴──────────┘              │                          │
│  ┌──────────────────────┐             │                          │
│  │ 运行规律              │             │                          │
│  └──────────────────────┘             │                          │
└─────────────────────────────────────────────────────────────────┘
```

### 1.2 核心问题

| 问题 | 说明 |
|------|------|
| 检票时间与检票口分离 | 时间配置在左侧主区，检票口选择在右侧侧栏，两者强关联却被放在页面两端 |
| 复选框列表空间不足 | 24 个检票口复选框挤在 240px 宽的侧栏，每行仅 2 个，需要大量垂直滚动 |
| 低频字段占主要位置 | "其他信息"（闸机站、广播模板等 8 个低频字段）与检票时间并排，干扰主流程 |
| 信息密度失衡 | 车次信息（8 字段）和列车信息（9 字段）横排，两列内容量差异大，视觉不平衡 |
| 运行规律独占整行 | 字段少但占满整行宽度，空间利用率低 |

---

## 二、重设计方案

### 2.1 整体布局

改为**左栏（55%）+ 右栏（45%）**两栏结构，取消固定宽度侧栏：

```
┌─────────────────────────────────────────────────────────────────┐
│  Header                                                          │
├──────────────────────────────┬──────────────────────────────────┤
│  左栏（55%）                  │  右栏（45%）                     │
│                              │                                  │
│  ① 车次信息                   │  ④ 检票配置                      │
│  ② 列车信息                   │     检票时间（4行）               │
│  ③ 运行规律                   │     股道 / 站台                  │
│  ④ 其他信息（折叠）            │     检票口（标签组）              │
│                              │     候车室（标签组）              │
│                              │     出站口（标签组）              │
└──────────────────────────────┴──────────────────────────────────┘
```

### 2.2 各区块规格

---

#### ① 车次信息

**位置**：左栏顶部  
**字段**：车次号、列车类型、到达时间、出发时间、始发站、终到站、到达车次、始发车次、接续车次（共 9 个）  
**布局**：`grid-cols-2`，车次号独占第一行全宽

```
┌─────────────────────────────────────────────────────┐
│ 车次信息                                              │
│ ┌─────────────────────────────────────────────────┐ │
│ │ * 车次号  [D3709_____________]                   │ │
│ └─────────────────────────────────────────────────┘ │
│ * 列车类型 [始发 ▼]    * 到达时间 [08:30]            │
│ * 始发站   [__________]  * 出发时间 [09:00]          │
│ * 终到站   [__________]  到达车次  [__________]      │
│   始发车次 [__________]  接续车次  [__________]      │
└─────────────────────────────────────────────────────┘
```

---

#### ② 列车信息

**位置**：左栏，车次信息下方  
**字段**：车型、编组、方向、担当局、等级、停车位、进站方向、出站方向、地标颜色、列车车底、上水作业、吸污作业（共 12 个）  
**布局**：`grid-cols-3`，列车车底独占一行，上水/吸污并排

```
┌─────────────────────────────────────────────────────┐
│ 列车信息                                              │
│ * 车型 [CR400AF ▼]  * 编组 [8 ▼]  * 方向 [正序 ▼]  │
│ * 担当局 [成局重段▼]  * 等级 [高铁▼]  * 停车位 [北▼] │
│   进站方向 [南 ▼]    出站方向 [南 ▼]  地标颜色 [绿 ■] │
│   列车车底 [_________________________________]       │
│ ┌──────────────────┐  ┌──────────────────┐          │
│ │ ☑ 上水作业  需要  │  │ □ 吸污作业  不需要│          │
│ └──────────────────┘  └──────────────────┘          │
└─────────────────────────────────────────────────────┘
```

---

#### ③ 运行规律

**位置**：左栏，列车信息下方  
**字段**：运行类型、起始有效期、终止有效期、起算基准（隔日时显示）、按周规律（规律开行时显示）  
**布局**：`grid-cols-2`，按周规律独占一行，日历预览折叠展开

```
┌─────────────────────────────────────────────────────┐
│ 运行规律                              [预览日历 ▼]   │
│ * 运行类型 [每日开行 ▼]  起始有效期 [__________]    │
│   终止有效期 [__________]                            │
│ （规律开行时）                                        │
│   按周规律 [一][二][三][四][五][六][日]               │
└─────────────────────────────────────────────────────┘
```

---

#### ④ 其他信息（默认折叠）

**位置**：左栏底部，折叠区块  
**字段**：闸机始发、闸机终到、始发时间、终到时间、广播模板、基本图号、到站天数、终到天数（共 8 个）  
**布局**：`grid-cols-2`，默认折叠，点击展开

```
┌─────────────────────────────────────────────────────┐
│ ▶ 其他信息                                           │
│ （展开后）                                            │
│   闸机始发 [__________]  闸机终到 [__________]      │
│   始发时间 [__:__]       终到时间 [__:__]            │
│   广播模板 [请选择 ▼]    基本图号 [__________]       │
│   到站天数 [0]           终到天数 [0]                │
└─────────────────────────────────────────────────────┘
```

---

#### ⑤ 检票配置（右栏）

**位置**：右栏，占满右栏高度  
**子区块**：检票时间 → 股道/站台 → 检票口 → 候车室 → 出站口

**检票时间**（保持现有交互，4 行）：

```
┌─────────────────────────────────────────────────────┐
│ 检票配置                                              │
│ 检票模板 [选择模板 ▼]              [另存为]           │
│ ┌──────────────────────────────────────────────┐    │
│ │ * 进站开检  [发点(09:00)▼]  [-][−25][+]  08:35│    │
│ │ * 进站停检  [发点(09:00)▼]  [-][ −5][+]  08:55│    │
│ │   出站开检  发点(09:00)     [-][  0][+]  09:00│    │
│ │   出站停检  发点(09:00)     [-][  0][+]  09:00│    │
│ └──────────────────────────────────────────────┘    │
└─────────────────────────────────────────────────────┘
```

**股道 / 站台**：

```
│ 股道 [1 ▼]   站台 [1 ▼]                             │
```

**检票口**（标签组，替代复选框列表）：

```
│ 检票口                                               │
│ [1A] [2A] [3A] [4A] [5A] [6A] [7A] [8A]            │
│ [9A] [10A][11A][12A]                                │
│ [1B] [2B] [3B] [4B] [5B] [6B] [7B] [8B]            │
│ [9B] [10B][11B][12B]                                │
```

选中态：`bg-[#5e6ad2] text-white border-[#5e6ad2]`  
未选态：`bg-white text-[#6B7280] border-[#D1D5DB]`  
每个标签：`h-6 px-2 text-[11px] rounded border`

**候车室**（标签组）：

```
│ 候车室                                               │
│ [候车大厅] [商务候车室]                               │
```

**出站口**（标签组）：

```
│ 出站口                                               │
│ [渝厦场南侧出站口] [渝厦场北侧出站口] [东场南侧出站口] │
```

---

### 2.3 尺寸规格

| 属性 | 当前值 | 新值 |
|------|--------|------|
| 抽屉总宽度 | `max-w-[1040px]` | `max-w-[1040px]`（保持不变） |
| 左栏宽度 | `flex-1`（约 800px） | `flex-[55]`（约 572px） |
| 右栏宽度 | `w-60`（240px 固定） | `flex-[45]`（约 468px） |
| 左右栏间距 | `border-l` | `border-l border-[#E5E7EB]` |
| 区块内边距 | `p-1.5` | `p-3`（适当放宽） |
| 区块间距 | `space-y-1` | `space-y-2` |

---

### 2.4 交互规格

#### 检票口标签组

- 点击标签切换选中/未选中状态
- 选中逻辑与现有 `chk` / `toggleChk` 函数保持一致，数据格式不变（逗号分隔字符串）
- 标签按 A 组（1A-12A）和 B 组（1B-12B）分两行排列，组间有 4px 间距

#### 其他信息折叠

- 默认折叠，标题行显示 `▶ 其他信息`
- 展开后显示 `▼ 其他信息`
- 折叠状态不持久化（每次打开抽屉默认折叠）
- 若折叠区内有非空字段，标题行显示橙色小圆点提示

#### 运行规律日历预览

- 保持现有逻辑，按钮文字和展开行为不变

---

## 三、与现有代码的对应关系

| 新区块 | 现有代码位置 | 变更类型 |
|--------|------------|----------|
| ① 车次信息 | `flex gap-2` 左侧 `flex-1` 卡片 | 布局调整，字段不变 |
| ② 列车信息 | `flex gap-2` 右侧 `flex-1` 卡片 | 布局调整，字段不变 |
| ③ 运行规律 | `!isFreightMode` 下的运行规律区块 | 移至左栏，内容不变 |
| ④ 其他信息 | `grid grid-cols-2` 右侧"其他信息"卡片 | 新增折叠包裹 |
| ⑤ 检票配置 | 左侧"检票时间"卡片 + 右侧侧栏 | 合并为右栏，检票口改标签组 |

---

## 四、不在本次范围内

- 非客运模式（`isFreightMode`）布局不变
- 字段逻辑、联动规则、数据结构不变
- 同步确认弹窗不变
- Header 区域不变
