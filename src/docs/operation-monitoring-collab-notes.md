# 作业盯控 — 协作记忆与优化备忘

> 来源：2026-04-12 用户评审同意后沉淀。用于后续改页面时对齐体验与 `spec.md`，不替代正式规格正文。

## 1. 接续车与作业单元（与 spec 一致的核心规则）

- 表格一行 = **作业单元**，分四类：**途径车、接续车、始发车、终到车**（定义见 `src/prototypes/operation-monitoring/spec.md`）。
- **接续车**：终到 + 始发组合，**合并一行**，股道/站台一致展示；车次形如 `A123 / D456`；车长、停靠信息可前后序分别展示。
- 列表排序：按**图定到点**或**图定发点**（依单元类型取有效时间）。
- 客流/位置列显示规则遵循 spec 表（如终到隐藏检票口、始发隐藏出站口等）。

## 2. 交互与规格对齐 — 已识别缺口（优先修复）

| 项 | 说明 |
|----|------|
| 手动派班入口 | `spec` 要求点击「派班」或异常可调起人员选择；实现中已有 Modal 逻辑，需在 UI 上提供明确入口（如作业格异常态、操作列）。 |
| 刷新数据 | 顶栏按钮需绑定真实刷新或改为禁用并说明。 |
| 声音提醒 | 若保留开关，需实现实际提示音或弱化文案避免「假功能」。 |
| 行展开 affordance | 展开图标被隐藏时，需引导用户发现可展开区域（行首图标或文案）。 |
| 完成作业 | 一键完成建议二次确认，防误触。 |

## 3. 盯控室使用场景 — 视觉与可读偏好（已共识）

- **远距离盯屏**：主数字（时间、人数）宜略大；辅助标签（图/实、缩写）可收进 Tooltip 或保证 **≥11–12px** 下限。
- **对比度**：关键状态避免仅靠红/绿；辅以文字或图标，照顾色弱。
- **信息密度**：主表保持可扫视；途径时间轴等次要信息可折叠或压缩高度。
- **横向滚动**：隐藏滚动条时需提供「可横向滑动」的可见提示或细滚动条，避免误以为无更多列。

## 4. 美观与一致性备忘

- 顶栏时钟风格与表格办公风需统一或刻意分区（避免无意识的字体混搭）。
- 图例需覆盖用户需理解的所有车次类型（含**接续**与 pill 颜色语义一致）。
- 文案：站台列避免单独用「站」易歧义，与 spec「站台」对齐更佳。
