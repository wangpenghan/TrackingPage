## 2. 不符合规范的具体问题

### 2.1 非客运模式 - 冗余字段问题

**问题位置**：代码结构中，非客运模式应完全隐藏某些字段，但目前仍有残留。

**具体现象**：
- ❌ 接续车次字段（`connectingTrain`）
- ❌ 进站方向字段（`entryDirection`）  
- ❌ 地标颜色字段（`landmarkColor`）
- ❌ 列车车底字段（`carriages`）

**业务冲突**：这些字段对非客运车次无意义，会造成用户困惑。

**规范要求**：在非客运模式中，这些字段应通过条件渲染完全移除。

**修复优先级**：P0（影响用户体验）

---

### 2.2 客运模式 - 第1行布局不符合

**问题位置**：代码行 305-503（主区域第一部分）

**当前结构**：
```tsx
<div className="flex gap-2">
  <div className="flex-1">
    {/* 车次信息 */}
  </div>
  <div className="flex-1">
    {/* 列车信息 */}
  </div>
</div>
```

**应为结构**：
```tsx
<div className="flex gap-2">
  <div className="flex-1">
    {/* 车次信息 */}
  </div>
  <div className="flex-1">
    {/* 时间 & 空间配置 */}
    {/* 包含：到达、发车、股道、站台、停车位、进站方向、出站方向 */}
  </div>
</div>
```

**问题影响**：列车信息被放在了第2行，导致"列车信息"和"检票时间"两个较长的区块都在第2行，造成布局不均衡。

**规范要求**：时间 & 空间配置应该在第1行的右侧，与"车次信息"对齐。

**修复优先级**：P0（影响整体布局）

---

### 2.3 客运模式 - 第2行检票时间右侧空白

**问题位置**：代码行 505-648（检票时间区块）

**当前状态**：
```tsx
{!isFreightMode && (
  <div className="flex gap-2">
    <div className="w-1/2 bg-white">  {/* ← 检票时间占左半 */}
      {/* 检票时间配置 */}
    </div>
    {/* 右半部分空白 */}
  </div>
)}
```

**应为结构**：
```tsx
{!isFreightMode && (
  <div className="flex gap-2">
    <div className="flex-1 bg-white">  {/* ← 列车信息（从第1行移来） */}
      {/* 列车信息 */}
    </div>
    <div className="flex-1 bg-white">  {/* ← 检票时间 */}
      {/* 检票时间配置 */}
    </div>
  </div>
)}
```

**问题影响**：检票时间配置虽然内容充分，但右侧 w-1/2 空间浪费，页面显得不均衡。

**规范要求**：第2行应为两栏平均分配（flex-1），无空白。

**修复优先级**：P0（影响视觉均衡）

---

### 2.4 客运模式 - 右侧侧栏结构错误（关键 Bug）

**问题位置**：代码行 700-791（w-72 侧栏）

**当前结构错误**：
```tsx
<div className="flex flex-1 overflow-hidden">
  <div className="flex-1 overflow-y-auto p-1.5 space-y-1.5">
    {/* 所有内容行 */}
    
    {/* ❌ 错误：w-72 侧栏被放在这里 */}
    <div className="w-72 overflow-y-auto border-l ...">
      股道、检票口、候车室、出站口
    </div>
  </div>
</div>
```

**应为结构**：
```tsx
<div className="flex flex-1 overflow-hidden">
  {/* 左侧主区域 */}
  <div className="flex-1 overflow-y-auto p-1.5 space-y-1.5">
    {/* 3个区块行 */}
  </div>
  
  {/* ✅ 正确：右侧侧栏与主区域并列 */}
  <div className="w-[240px] overflow-y-auto border-l ...">
    股道、检票口、候车室、出站口
  </div>
</div>
```

**问题影响**：
- w-72 侧栏显示在表格行底部，而不是固定在右侧
- 用户无法同时看到表格和侧栏信息
- 侧栏宽度 288px 偏宽，应缩至 240px

**规范要求**：侧栏应作为 flex 容器中的第二列，与主区域并列固定。

**修复优先级**：P0（结构性 Bug）

---

### 2.5 右侧侧栏宽度

**当前**：`w-72` = 288px

**应为**：`w-[240px]` = 240px

**理由**：根据设计规范，侧栏应缩窄以给主区更多空间。

**修复优先级**：P1（UI调整）
