📋页面概述

业务场景

到发盯控页面 V2 是面向调度人员的列车到发监控看板，用于展示列车到发信息，提供作业监控、旅服信息、站车信息等功能模块。支持单站和代管两种控制模式。

用户角色

  • 主要用户：车站调度员、值班站长
  • 使用场景：实时监控、异常预警、作业协调、计划干预

核心功能

列车到发监控 作业监控 旅服信息 计划干预 多抽屉交互 简洁/标准双模式

🗂️抽屉组件清单

到发盯控 V2 包含多个抽屉组件，通过双击不同区域触发：

📋 车次详情抽屉 (TrainDetailDrawer)
触发：点击详情按钮
展示车次完整信息，包含多个标签页
⚙️ 作业详情抽屉 (OperationDetailDrawer)
触发：双击作业卡片
展示检票、站台、出站、结合部作业详情
🚰 上水吸污配置 (WaterSewageConfigDrawer)
触发：双击上水/吸污标签
配置列车的上水和吸污服务车厢
📝 客运记录抽屉 (PassengerRecordDrawer)
触发：双击客运记录标签
展示遗失物品、重点旅客等客运记录
🎯 计划干预抽屉 (PlanInterventionDrawer)
触发：双击车次数据面板
对车次进行计划干预操作
🚂 编组维护抽屉 (TrainFormationDrawer)
触发：双击车次号/地标
维护列车编组信息
🛤️ 途径站信息 (RouteStationsDrawer)
触发：双击运行区间
展示列车途径的所有站点信息
👥 客流信息抽屉 (PassengerFlowDrawer)
触发：双击客流信息
展示详细的客流数据
📊 计划详情抽屉 (PlanDetailDrawer)
触发：双击旅服作业
展示计划执行详情
🔧 操作抽屉 (OperationDrawer)
触发：双击时间/股道/检票口等
时间调整、股道调整、检票口调整等
⚡ 情景模式抽屉 (SceneModeDrawer)
触发：点击情景模式按钮
专运模式、应急模式、大面积晚点模式
🔍 计划筛选抽屉 (PlanFilterDrawer)
触发：点击筛选按钮
按列车类型、股道、候车室筛选

简洁模式 vs 标准模式

模式 显示内容 适用场景
简洁模式 只显示状态标签（正常/大客流/正在作业/异常） 快速浏览、大屏展示
标准模式 显示详细数值和人员信息 详细监控、调度操作

👆交互方式

单击交互

  • 单击行 选中/取消选中列车，高亮显示
  • 单击详情按钮 打开车次详情抽屉
  • 单击接续车次 跳转到接续车次并高亮

双击交互

  • 双击车次号 打开编组维护抽屉
  • 双击时间 打开时间调整抽屉
  • 双击股道/站台 打开股道调整抽屉
  • 双击检票口 打开检票口调整抽屉
  • 双击作业卡片 打开作业详情抽屉
  • 双击上水/吸污标签 打开上水吸污配置抽屉
  • 双击运行区间 打开途径站信息抽屉
  • 双击客流信息 打开客流信息抽屉
  • 双击车次数据面板 打开计划干预抽屉

键盘交互

📡Axure API 规范

事件列表 (eventList)

事件名称 描述 payload
on_train_select 选中列车时触发 string (列车ID)
on_station_change 切换车站时触发 string (车站名称)
on_view_mode_change 视图模式切换时触发 string (normal/intervention)
on_data_change 数据发生变化时触发 JSON string
on_filter_change 筛选条件变化时触发 JSON string

动作列表 (actionList)

动作名称 描述 参数
select_train 选中指定列车 string (列车ID)
switch_station 切换到指定车站 string (车站名称)
set_view_mode 设置视图模式 string (normal/intervention)
refresh_data 刷新数据 -
set_search_term 设置搜索关键词 string
toggle_dark_mode 切换深色模式 -
set_filters 设置筛选条件 JSON string
