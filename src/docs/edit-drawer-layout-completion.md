```tsx

  {/* 检票时间 - 全宽 */}
```

```tsx
<div className="flex gap-2">
  <div className="flex-1 bg-white rounded-lg border border-[#E5E7EB] p-2">
    {/* 检票时间 - flex-1（50%宽度） */}

    {/* 其他信息 - flex-1（50%宽度） */}
```

**关键改动**：
- 行 654：添加外层 `<div className="flex gap-2">` 容器
- 行 655：检票时间改为 `flex-1`（原为 `flex-1`，保持不变）
- 行 796：其他信息改为 `flex-1`（原为独立全宽）
- 行 846：添加外层容器闭合 `</div>`
