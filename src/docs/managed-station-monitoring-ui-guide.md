## 一、页面定位

### 1.1 业务场景
代管盯控是面向调度人员的**多车站列车监控看板**，用于同时监控多个代管车站的列车到发情况。区别于单站盯控，本页面以**时间轴为核心**，横向展示列车在各站点的运行轨迹。

### 1.2 用户角色
- **主要用户**：车站调度员、值班站长
- **使用场景**：实时监控、异常预警、作业协调

## 三、功能模块详解

### 3.1 工具栏

#### 功能入口

| 元素 | 说明 | 交互 |
|------|------|------|
| **页面标题** | "代管盯控" + 副标题"甘特图风格" | 点击返回首页 |
| **搜索框** | 输入车次号快速定位 | 实时筛选 |
| **缩放控制** | 缩小/放大/重置按钮 + 当前比例显示 | 点击调整时间轴刻度 |
| **当前时间** | 实时显示系统时间 | 自动更新 |
| **主题切换** | 太阳/月亮图标按钮 | 切换深色/浅色模式 |
| **设置按钮** | 齿轮图标 | 打开配置弹窗 |

#### 缩放控制说明
- **缩小**：时间轴压缩，显示更大时间范围
- **放大**：时间轴展开，显示更精细时间刻度
- **重置**：恢复默认缩放比例和位置

### 3.3 时间轴

#### 展示规则

| 特性 | 说明 |
|------|------|
| **时间范围** | 默认 06:00 - 24:00（可配置） |
| **刻度显示** | 每小时一个主刻度，显示 HH:00 |
| **当前时间线** | 红色竖线贯穿整个甘特图区域，带脉冲动画 |
| **网格背景** | 每小时一列的浅色竖线网格 |

#### 交互方式

| 操作 | 效果 |

| **鼠标拖拽** | 左右平移时间轴，查看不同时间段 |

| **点击缩放按钮** | 按固定步长缩放 |

### 3.4 车次卡片

#### 卡片结构

```
┌─────────────────────────────────────────┐
│ ┌──────┐  成都东 → 重庆东    ● 16正北   │  ← 头部信息区
│ │G8888 │                               │
│ └──────┘                               │
├─────────────────────────────────────────┤
│ ┌────────┐ ┌────────┐ ┌──────┐         │  ← 核心数据区
│ │ 17:00  │ │ 17:30  │ │  5   │         │
│ │ 到点   │ │ 发点   │ │股道  │         │
│ └────────┘ └────────┘ └──────┘         │
├─────────────────────────────────────────┤
│ [检票] [站台] [出站] [水污]             │  ← 作业状态区
└─────────────────────────────────────────┘
```

#### 信息元素说明

| 元素 | 说明 | 视觉样式 |
|------|------|----------|
| **车次号** | 如 G8888、D1234 | 橙色圆角标签，黑字粗体 |
| **运行区间** | 始发站 → 终到站 | 灰色小字，箭头连接 |
| **地标信息** | 编组数+正倒序+方向，如"16正北" | 蓝色圆点 + 文字，浅蓝背景 |
| **到点/发点** | 到达和出发时间 | 灰色圆角框，等宽字体 |
| **延误标记** | 晚点时显示 +N 分钟 | 红色小字，跟在时间后 |
| **股道号** | 停靠股道，如 5、12 | 黄色圆角框，黑字粗体 |
| **作业按钮** | 检票/站台/出站/水污 | 根据状态变色 |

#### 作业状态颜色

| 状态 | 颜色 | 说明 |
|------|------|------|
| 未开始 | ⬜ 浅灰 | 灰色背景 `#F2F2F2` |
| 进行中 | 🟢 浅绿（检票/水污）<br>🔵 浅蓝（其他） | `#CAF982` / `#81D3F8` |
| 已完成 | 🟢 浅绿 | `#CAF982` |
| 异常 | 🔴 浅红 | `#EF9A9A` |

#### 地标颜色规则

地标指示器显示"编组数+正倒序+方向"，颜色根据规则变化：

| 编组 | 正倒序 | 上下行 | 颜色 |
|------|--------|--------|------|
| 16辆 | 正序 | - | 🟡 黄色 |
| 16辆 | 倒序 | - | 🟢 绿色 |
| 8辆 | 正序 | 上行 | 🔵 蓝色 |
| 8辆 | 正序 | 下行 | 🟡 黄色 |
| 8辆 | 倒序 | 上行 | 🟢 绿色 |
| 8辆 | 倒序 | 下行 | 🟣 紫色 |

## 四、交互方式

### 4.1 时间轴交互

| 手势/操作 | 效果 | 适用场景 |

## 六、业务规则

### 6.1 车次排列规则

1. **时间排序**：按到达时间从左到右排列
2. **防重叠**：同一时间点的车次自动错行展示
3. **行高自适应**：根据车次数量自动计算行高

### 6.2 时间轴规则

1. **默认范围**：06:00 - 24:00
2. **缩放范围**：2px/分钟 - 12px/分钟
3. **当前时间**：红色竖线实时标记

### 6.3 数据展示规则

1. **延误显示**：晚点时显示 "+N" 红色标记
2. **作业状态**：实时反映检票、站台、出站、上水、吸污状态
3. **地标信息**：根据编组、正倒序、方向自动计算颜色
