# 铁路列车运行调度监控系统 - 功能文档

## 一、系统概述

铁路列车运行调度监控系统是一个面向铁路调度人员的实时监控平台，旨在提高列车运行监控效率、优化调度决策流程。系统包含四个核心功能模块，覆盖从列车运行监控到人员派班的全流程管理。

## 三、代管盯控模块

### 3.1 模块定位

代管盯控是系统的核心入口，采用时间轴可视化方式展示多车站列车运行状态，帮助调度员直观掌握列车在各车站的到发时间和股道占用情况。

### 3.2 功能清单

#### 3.2.1 时间轴功能

| 功能     | 描述                  |
| ------ | ------------------- |
| 时间刻度显示 | 24小时时间刻度，每30分钟一个主刻度 |
| 当前时间线  | 蓝色竖线标记当前时刻，带三角形指示器  |
| 拖拽滚动   | 支持鼠标拖拽水平滚动时间轴       |
| 回到当前   | 一键定位到当前时间位置         |

#### 3.2.2 面板布局

| 功能     | 描述               |
| ------ | ---------------- |
| 多车站面板  | 按车站分组显示，每个面板独立展示 |
| <br /> | <br />           |
| <br /> | <br />           |
| 面板排序   | 支持拖拽调整车站显示顺序     |

#### 3.2.3 列车卡片

| 功能     | 描述                      |
| ------ | ----------------------- |
| 基本信息展示 | 车次号、到发时间、股道             |
| 服务类型标识 | 始发（蓝）、终到（绿）、途径（灰）       |
| 运行状态标识 | 正常（蓝边框）、早点（绿边框）、晚点（红边框） |
| 晚点时间显示 | 正数表示晚点分钟数，负数表示早点        |
| 变更股道标记 | 原股道划线显示，新股道橙色高亮         |
| 站停时间条  | 显示列车在站停留时长（分钟）          |
| 已过列车淡化 | 当前时间之前的列车显示为半透明         |

#### 3.2.4 连线功能

| 功能    | 描述               |
| ----- | ---------------- |
| 同车次连线 | 同一车次在不同车站间显示连接线  |
| 选中高亮  | 点击列车后高亮显示相关连线    |
| 虚线样式  | 未选中时连线为虚线，选中时为实线 |

#### 3.2.5 缩放控制

| 功能    | 描述                 |
| ----- | ------------------ |
| 放大/缩小 | 调整时间轴像素密度（px/min）  |
| 最佳缩放  | 一键切换到避免卡片重叠的最小缩放比例 |
| 中心保持  | 缩放后保持视图中心位置不变      |

#### 3.2.6 配置弹窗

| 功能   | 描述               |
| ---- | ---------------- |
| 车站配置 | 调整监控车站、顺序拖拽      |
| 显示设置 | 过滤已过/未来列车、连线显示开关 |
| 提醒设置 | 早晚点阈值配置          |

### 3.3 交互设计

| 交互     | 触发     | 反馈               |
| ------ | ------ | ---------------- |
| 点击列车卡片 | 鼠标点击   | 卡片放大、边框高亮、相关连线高亮 |
| 悬停列车卡片 | 鼠标悬停   | 卡片轻微上浮、阴影增强      |
| 拖拽时间轴  | 鼠标按住拖动 | 水平滚动视图           |
| 调整缩放   | 点击按钮   | 时间轴缩放、卡片位置重排     |

## 四、到发盯控模块

### 4.1 模块定位

到发盯控以表格形式展示列车到发详细信息，支持数据编辑、筛选排序，是日常调度的数据操作界面。

### 4.2 功能清单

#### 4.2.1 表格信息展示

| 列名   | 内容                  |
| ---- | ------------------- |
| 车次   | 车次号 + 类型颜色标识        |
| 到点   | 图定到点 + 实际到点 + TD时间  |
| 发点   | 图定发点 + 实际发点 + TD时间  |
| 股道   | 当前股道（支持变更显示）        |
| 站台   | 站台编号                |
| 检票口  | 检票口编号               |
| 出站口  | 出站口编号（可选）           |
| 列车属性 | 编组数 + 正倒序 + 上下行     |
| 运行区间 | 始发站 → 终到站           |
| 重点标记 | 上水/吸污/行包/快运/超员/VIP等 |
| 接续关系 | 前后车次接续显示            |

#### 4.2.2 时间显示模式

| 模式    | 说明                   |
| ----- | -------------------- |
| 图定时间  | 灰色基础显示               |
| 实际时间  | 蓝色强调显示               |
| TD时间  | 可选的第三方时间             |
| 早晚点标记 | 早（蓝标签）/晚（橙标签）/正（绿标签） |

#### 4.2.3 编辑功能

| 功能     | 操作方式            |
| ------ | --------------- |
| 股道调整   | 双击股道单元格，弹窗选择新股道 |
| 检票口调整  | 双击检票口单元格，弹窗选择   |
| 出站口调整  | 双击出站口单元格，弹窗选择   |
| 列车属性配置 | 拖拽排序标签顺序        |

#### 4.2.4 筛选与排序

| 功能   | 描述         |
| ---- | ---------- |
| 车次搜索 | 输入框实时过滤    |
| 时间排序 | 按到点/发点升序排列 |
| 状态筛选 | 正常/晚点/早点筛选 |

#### 4.2.5 多站盯控

| 功能     | 描述            |
| ------ | ------------- |
| 车站切换器  | 顶部紧凑型切换器，支持多选 |
| 同时管辖上限 | 最多同时监控5个车站    |
| 独立数据   | 每个车站独立数据展示    |

#### 4.2.6 途径站信息

| 功能    | 描述           |
| ----- | ------------ |
| 途径按钮  | 点击弹出途径站详情    |
| 垂直时间线 | 展示10-24个途径站点 |
| 当前站标记 | 高亮显示当前所在站点   |
| 到发时间  | 每站显示到达/出发时间  |
| 限速信息  | 显示各站限速       |

#### 4.2.7 任务简报

| 功能    | 描述               |
| ----- | ---------------- |
| 详情弹窗  | 点击"详情"按钮打开       |
| 统计概览  | 总任务/已完成/异常/进度环   |
| 时间轴   | 横向6列时间节点布局       |
| 主节点标识 | 临/到/发标签突出显示      |
| 任务分类  | 广播/引导屏/闸机/人员四种类型 |

## 五、作业盯控模块

### 5.1 模块定位

作业盯控以作业单元为核心，实时监控各作业环节的执行状态，确保列车作业流程顺利进行。

### 5.2 功能清单

#### 5.2.1 作业单元展示

| 信息   | 内容          |
| ---- | ----------- |
| 车次信息 | 车次号 + 类型标识  |
| 作业类型 | 始发/终到/接续    |
| 到发时间 | 图定时间 + 实际时间 |
| 股道站台 | 股道 + 站台编号   |
| 检票口  | 检票口编号       |
| 运行状态 | 正常/早点/晚点    |

#### 5.2.2 状态监控

| 状态  | 颜色 | 说明      |
| --- | -- | ------- |
| 正常  | 绿色 | 作业按计划进行 |
| 晚点  | 橙色 | 存在延误    |
| 缺员  | 红色 | 人员不足    |
| 待开始 | 黄色 | 尚未开始    |
| 已完成 | 蓝色 | 作业完成    |
| 不适用 | 灰色 | 无需此项    |

#### 5.2.3 重点事项标识

| 事项 | 图标 | 说明     |
| -- | -- | ------ |
| 上水 | 💧 | 列车上水作业 |
| 吸污 | 🚽 | 列车吸污作业 |
| 行包 | 📦 | 行李包裹作业 |
| 快运 | ⚡  | 快运货物作业 |
| 超员 | 👥 | 乘客超员预警 |
| 晚点 | ⏱️ | 列车晚点提醒 |

#### 5.2.4 作业人员显示

| 功能   | 描述         |
| ---- | ---------- |
| 人员头像 | 显示作业人员头像   |
| 状态指示 | 在线/离线/忙碌状态 |
| 快捷操作 | 点击查看详情或分配  |

#### 5.2.5 主题切换

| 功能      | 描述       |
| ------- | -------- |
| 浅色/深色主题 | 一键切换显示模式 |
| 自动保存    | 记住用户偏好   |

## 六、手动派班模块

### 6.1 模块定位

手动派班用于作业人员分配，支持班组长或调度员为具体作业任务分配执行人员。

### 6.2 功能清单

#### 6.2.1 车次信息展示

| 信息   | 内容       |
| ---- | -------- |
| 车次号  | 当前派班的车次  |
| 到发时间 | 到点 + 发点  |
| 股道站台 | 股道 + 站台  |
| 服务类型 | 始发/终到/途径 |

#### 6.2.2 作业列表管理

| 功能   | 描述                  |
| ---- | ------------------- |
| 作业类型 | 站台作业/检票作业/出站作业/上水吸污 |
| 添加作业 | 点击"+"按钮新增作业项        |
| 删除作业 | 移除不需要的作业项           |
| 位置信息 | 显示作业位置              |
| 时间范围 | 显示作业时间段             |

#### 6.2.3 人员选择

| 功能    | 描述          |
| ----- | ----------- |
| 班组筛选  | 按班组分类筛选人员   |
| 姓名搜索  | 输入框实时搜索     |
| 已分配标识 | 已分配人员显示勾选标记 |
| 状态显示  | 在线/离线/忙碌状态  |

#### 6.2.4 派班操作

| 操作   | 描述           |
| ---- | ------------ |
| 保存草稿 | 保存当前分配状态     |
| 正式派班 | 提交派班结果，校验完整性 |
| 重置派班 | 清空当前分配重新开始   |

### 6.3 交互流程

1. 选择待分配的作业项（点击高亮）
2. 从右侧人员列表选择人员
3. 系统自动分配并更新显示
4. 重复以上步骤完成所有分配
5. 点击"正式派班"提交结果
