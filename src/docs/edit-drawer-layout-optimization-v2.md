## 核心需求

### 1. 非客运模式 - 精简布局

**应该显示**：
- 基础信息（包含到达时间、发车时间）
- 编组配置
- 作业配置
- 运行规律（内容和客运一样）

**不应该显示**：
- ❌ 时间&空间分组（时间字段已合并到基础信息）
- ❌ 其他信息分组

**字段分配**：
```
【基础信息】
  车次号 (*)
  列车类型 (*) | 到达时间 (*)
  始发站 (*)   | 发车时间 (*)
  终到站 (*)
```

---

### 2. 客运模式 - 优化布局

#### 第1行改进

**当前**：车次信息（flex-1） + 时间&空间（flex-1）

**改为**：车次信息（flex-1，**包含到达、出发时间**）+ 列车信息（flex-1）

```
【车次信息】
  车次号 (*) 
  列车类型 (*)  | 到达时间 (*)
  始发站 (*)    | 出发时间 (*)
  终到站 (*)
  到达车次      | 始发车次      | 接续车次

【列车信息】
  车型 (*)      | 编组 (*)    | 方向 (*)
  担当局 (*)    | 等级 (*)
  停车位 (*)    | 进站方向         | 出站方向
  地标颜色(只读) | 列车车底
```

**移除**：时间&空间单独分组

#### 第2行改进

**当前**：列车信息（w-1/2）+ 检票时间（w-1/2）

**改为**：检票时间（flex-1，保留）

**说明**：列车信息已移至第1行，所以第2行只保留检票时间

```
【检票时间】
  进站开检 (*) | 下拉 + 微调 + 时间
  进站停检 (*) | 下拉 + 微调 + 时间
  出站开检     | 显示 + 微调 + 时间
  出站停检     | 显示 + 微调 + 时间
```

#### 右侧侧栏优化

**当前**：
- 股道、站台（大数字，只读）
- 检票口（12个选项）
- 候车室（2个选项）
- 出站口（3个选项）
- 作业配置（上水、吸污）
- ❌ 编组摘要（删除）
- ❌ 基本状态（删除 - 内容重复在顶栏）

**改为**：
- 股道、站台（**改为可编辑下拉框**，是唯一编辑入口）
- 检票口（12个选项）
- 候车室（2个选项）
- 出站口（3个选项）
- 作业配置（上水、吸污）

**说明**：
- ✅ 股道、站台保留在侧栏，改为可编辑（删除主区"时间&空间"里的股道站台）
- ❌ 删除编组摘要（第1行列车信息已显示）
- ❌ 删除基本状态（内容在顶栏已显示）

#### 第3行：运行规律

**保留**：运行规律区块（和当前一样，但放在第2行检票时间后面）

```
【运行规律】
  运行类型 [每日开行▼]  
  （可选）起算基准 [从起始日] [从次日]
  （条件显示）按周规律 [一二三四五六日]
  起始有效期 [____]  终止有效期 [____]
  日历展示（按有效期截断）
```

## 5. 布局设计思路

### 原则

1. **垂直紧凑**：各区块贴近排列，gap 减少
2. **水平利用**：两列/三列布局最大化利用宽度
3. **响应式**：确保 1366px+ 宽度下无滚动
4. **视觉分层**：通过颜色/边框/间距区分区块

### 具体方案

#### 非客运缩小高度

```tsx
// 区块间距改小
gap={1} // 改为 1 而不是 1.5

// 内部字段间距改小
gap-y-0.5 // 改为 0.5 而不是 1

// label 和输入框间距改小  
mb-0.5 // 改为 0.5

// padding 改小
p-1 // 改为 1 而不是 2
```

#### 客运第1行紧凑化

```tsx
// 车次信息内使用更紧凑的 grid
grid grid-cols-2 gap-1 // 改为 gap-1

// 到达/出发时间并排显示
<div className="grid grid-cols-2 gap-1">
  <input label="到达" />
  <input label="出发" />
</div>
```

#### 检票时间紧凑化

```tsx
// 检票时间行改为更紧凑的布局
<div className="flex items-center gap-1">
  <label>进站开检</label>
  <select> ... </select>  // 下拉框改窄
  <button>-</button>      // 缩小按钮
  <span>±值</span>        // 紧凑显示
  <span>时间</span>       // 结果显示
</div>
```

#### 日历简化

```tsx
// 选项 1：隐藏日历，只显示控制器
// 选项 2：日历改为紧凑样式（减小字体、gap）
// 建议：选项 2，样式优化日历
```
