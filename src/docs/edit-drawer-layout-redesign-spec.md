# 编辑抽屉布局重设计方案

**版本：** v1.0  
**日期：** 2026-05-08  
**适用模块：** 客运模板 / EditDrawer / 客运车次 & 非客运车次布局

---

## 1. 现状问题诊断

### 1.1 结构性 Bug（最优先修复）

当前代码存在一个结构性错误：右侧功能栏（`w-72`，包含股道、检票口、候车室、出站口、作业配置）被错误地嵌套在主区域 `flex-1 overflow-y-auto` 的 `space-y-1.5` 容器底部，而不是与主区域并列的独立侧边栏。

```
// 当前错误结构
<div class="flex flex-1 overflow-hidden">
  <div class="flex-1 overflow-y-auto space-y-1.5">    ← 主区域
    <行1: 车次/列车信息>
    <行2: 检票时间（仅客运）>
    <行3: 运行规律>
    <div class="w-72 ...">                             ← ❌ 错误：放在主区域底部
      股道/检票口/作业配置
    </div>
  </div>
  // ← 这里才是正确位置
</div>
```

**应为并列结构：**
```
<div class="flex flex-1 overflow-hidden">
  <div class="flex-1 overflow-y-auto">  ← 左侧主区域
    ...
  </div>
  <div class="w-[240px] border-l">     ← ✅ 右侧独立侧栏
    ...
  </div>
</div>
```

### 1.2 非客运车次：页面空白严重

| 问题 | 描述 |
| :--- | :--- |
| 抽屉过宽 | `max-w-[1200px]` 对于非客运少量字段完全不必要 |
| 横向留白 | 行1为两栏（基础信息 + 列车编组），各占 50%，但字段极少，大量空白 |
| 纵向留白 | 运行规律下方的 `w-72` 侧栏位于页面底部，悬空感强 |
| 字段分散 | 时间（到达/发车）在运行规律区域没有显式位置，需要从其他地方补充 |
| 冗余字段 | 非客运不需要：进站方向、地标颜色、列车车底、接续车次等 |

### 1.3 客运车次：布局不均衡，有大块空白

| 问题 | 描述 |
| :--- | :--- |
| 检票时间仅占 w-1/2 | 客运行2的检票时间只用了左半部分，右半边完全空白 |
| 右侧栏位置错误 | w-72 嵌套在主区底部，不是固定右侧 |
| 股道/站台不显眼 | 核心字段（股道、站台）被放在底部的 w-72 里，不够突出 |
| 到达/发车时间没有专属区块 | 时间字段分散，没有集中的「时间配置」区域 |
| 重复信息 | 检票时间配置中的「发点/到点」下拉框重复展示了相同的时间参考 |

## 2. 非客运车次：全新紧凑布局

### 2.1 设计原则

- 抽屉宽度缩窄至 `max-w-[780px]`，与字段量匹配
- 去掉右侧栏，单主区域布局，通栏流式排布
- 按使用优先级由上到下排序：时间 → 空间 → 编组 → 作业 → 运行规律

### 2.2 整体布局线框

### 2.3 字段清单（仅保留必要字段）

| 区块 | 字段 | 必填 |
| :--- | :--- | :--- |
| 基础信息 | `trainNo`、`trainType`、`fromStation`、`toStation` | ✓ |
| 时间 & 空间 | `arrivalTime`、`departureTime`、`track`、`platform`、`parkingSpot` | ✓ |
| 编组配置 | `model`、`formation`、`formationDir`、`bureau`、`trainClass` | ✓ |
| 作业配置 | `hasWater`、`hasSuction` | 可选 |
| 运行规律 | `cycle`、`rule`、`validStart`、`validEnd` | ✓ |

**从非客运布局中完全移除的字段：**
- `arrivalTrainNo`、`departureTrainNo`、`connectingTrain`（接续不适用）
- `entryDirection`（只对客运有意义）
- `landmarkColor`（客运专用）
- `carriages`（车底不需要）
- `waitingRoom`、`gates`、`exitGate`（客运专用）
- 所有检票偏移字段

## 3. 客运车次：布局重组

### 3.1 设计原则

- 抽屉宽度保持 `max-w-[1180px]`（或缩至 `max-w-[1040px]`）
- 修复结构性 Bug：实现真正的左主区 + 右固定侧栏
- 左主区填满：时间配置区块补上，消除检票时间的右侧大空白
- 右侧栏：聚焦核心速查信息（股道/站台、检票口、候车室、出站口）

**变化**：
- 原有 `arrivalTime`/`departureTime` 没有专属输入区，现在有了

## 4. 对比总结

### 4.1 抽屉宽度

| 模式 | 当前 | 优化后 | 说明 |
| :--- | :--- | :--- | :--- |
| 非客运 | `max-w-[1200px]` | `max-w-[780px]` | 字段少，紧凑布局 |
| 客运 | `max-w-[1200px]` | `max-w-[1040px]` | 侧栏缩至 240px，主区稍缩 |

### 4.2 各区块位置变化

#### 非客运

| 区块 | 当前位置 | 优化后 |
| :--- | :--- | :--- |
| 基础信息 | 行1左（flex-1） | 行1（全宽 2 列 Grid） |
| 列车编组 | 行1右（flex-1） | 行3（全宽 2 行 Grid） |
| 时间（到达/发车） | 无独立区块 | **行2（新增独立区块）** |
| 空间（股道/站台/停车位） | 底部 w-72 | 行2（与时间合并） |
| 作业配置 | 底部 w-72 | **行4（专属横向双按钮）** |
| 运行规律 | 行2 | 行5（最底部） |

#### 客运

| 区块 | 当前位置 | 优化后 |
| :--- | :--- | :--- |
| 车次信息 | 行1左（flex-1） | 行1左（flex-1，不变） |
| 列车信息 | 行1右（flex-1） | 行2左（w-1/2） |
| 时间（到达/发车）| 无独立区块 | **行1右（时间&空间区块）** |
| 空间（股道/站台/停车位）| 底部 w-72 | **行1右（时间&空间区块）** |
| 检票时间 | 行2左（w-1/2，右边空） | 行2右（w-1/2，与列车信息对齐） |
| 检票口/候车室/出站口 | 底部 w-72（错误嵌套） | **右侧固定侧栏（结构修复）** |
| 运行规律 | 行3 | 行3（不变） |

### 4.3 去掉的重复/冗余信息

| 字段 | 在哪里重复或冗余 | 处理方式 |
| :--- | :--- | :--- |
| 股道、站台 | 客运：既在行1列车信息中，又在底部w-72里 | 统一放入行1「时间&空间」区块 |
| 停车位 | 客运：在列车信息中，与空间配置分离 | 移至「时间&空间」区块 |
| 检票时间中的时间参考 | 每个时间行都有下拉选「发点/到点」，重复展示时间值 | 保留（交互需要），但精简样式 |
| 非客运中的接续车次等 | 在非客运里无意义 | 整个区块从非客运布局移除 |

| 优先级 | 任务 | 影响 |
