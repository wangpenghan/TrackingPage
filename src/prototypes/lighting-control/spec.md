# 照明控制页面设计规格

## 📋 业务与功能

### 1.1 核心目标
照明控制页面用于车站各区域的照明管理，支持自动/人工控制模式切换、照明详情查看、开关与回路控制等功能。

### 1.2 功能模块

- **区域管理**：展示车站各区域（站台、候车室、出站口等）的照明控制卡片
- **照明详情**：点击照度按钮查看24小时照明情况，包含夜间模式、计划优先、照度优先区域
- **控制模式切换**：支持一键人工/一键自动控制模式切换
- **自动恢复倒计时**：人工控制模式下，开启自动恢复时显示30分钟倒计时
- **开关与回路控制**：整合的开关面板，支持全开、全关、半开、1/4开，不同模式对应不同回路预设
- **白天/夜间模式**：根据时间自动切换深色/浅色主题

### 1.3 开关与回路整合设计（v1.1更新）

**设计思路**：采用左右分栏布局，左侧开关模式卡片直接显示回路缩略预览，右侧展示详细回路列表，强化开关模式与回路的视觉关联。

**信息架构**：
```
开关与回路控制抽屉 (720px)
├── 头部区域
│   ├── 标题"开关与回路控制"
│   └── 关闭按钮
├── 左右分栏布局
│   ├── 左侧：开关模式选择面板 (240px)
│   │   ├── 全开模式卡片
│   │   │   ├── 模式图标 + 模式名称
│   │   │   ├── 回路缩略预览（10个小圆点表示）
│   │   │   └── 模式提示（预设模式/可调整）
│   │   ├── 1/2开-A模式卡片
│   │   ├── 1/2开-B模式卡片
│   │   ├── 1/4开模式卡片
│   │   └── 全关模式卡片
│   └── 右侧：回路详情编辑面板
│       ├── 面板标题 + 编辑提示
│       ├── 回路列表（10个回路）
│       │   ├── 左侧：回路状态指示器 + 回路名称 + 实际状态
│       │   └── 右侧：已选/未选徽章
│       └── 摘要信息区
│           ├── 已选回路数量
│           └── 当前模式名称
└── 底部操作区
    ├── 取消按钮
    └── 确定按钮
```

**交互逻辑**：
- 左侧模式卡片点击切换，卡片内用10个小圆点直观显示该模式对应的回路组合
- 全开/全关模式：回路只显示状态，不可编辑，卡片提示"预设模式"
- 半开/1/4开模式：默认自动关联对应回路，支持手动点击调整，卡片提示"可调整"
- 右侧回路列表显示详细信息，包括实际开关状态和当前选择状态
- 底部摘要区实时显示已选回路数量和当前模式

## 📊 内容规划

### 2.1 信息架构

```
照明控制页面
├── 顶部工具栏
│   ├── 区域选择器
│   ├── 当前照度显示 + 照明详情按钮
│   ├── 一键人工/一键自动按钮
│   └── 回路控制快捷按钮(全开、1/2开-A、1/2开-B、1/4开、全关)
├── 区域卡片网格
│   └── 每个区域卡片
│       ├── 区域名称
│       ├── 控制模式(自动/人工) + 切换开关
│       ├── 照度按钮 + 开关模式按钮
│       └── 自动恢复开关 + 倒计时显示(如适用)
├── 照明详情抽屉
│   └── 24小时时间轴
└── 开关与回路控制抽屉
    ├── 左侧：开关模式选择（带回路预览）
    └── 右侧：回路详情编辑
```

### 2.2 数据来源

- **数据类型**：区域照明控制数据、照明详情数据、回路数据
- **数据源**：`mock-data.ts` 中的 `mockAreas`、`mockLightingDetails`、`mockCircuits`
- **关键字段**：
  - `area`: 区域信息
  - `lightingHour`: 每小时照明情况
  - `circuit`: 回路信息
  - `switchModeConfig`: 开关模式配置

## 🎨 布局与结构

### 3.1 整体布局

- **布局模式**：顶部工具栏 + 区域卡片网格布局
- **关键尺寸**：
  - 页面内边距：16px
  - 卡片圆角：12px
  - 按钮圆角：8px
  - 抽屉宽度：720px（开关与回路控制）
  - 左侧模式面板宽度：240px

### 3.2 视觉规范

**色彩规范**：
- 背景渐变：
  - 浅色：`linear-gradient(180deg, #FFFFFF 0%, #FAF8F5 100%)`
  - 深色：`linear-gradient(180deg, #0D1B2A 0%, #0A1520 100%)`
- 夜间模式区域：`#1C1C1E`（黑色）
- 计划优先区域：`#007AFF`（蓝色）
- 照度优先区域：`#FF9500`（黄色）
- 主按钮：`#007AFF`
- 危险按钮：`#FF3B30`
- 成功色：`#34C759`

**照明详情时间轴区域颜色**：
- 夜间模式(0-6点,15-24点)：黑色 `#1C1C1E`
- 计划优先(车次触发)：蓝色 `#007AFF`
- 照度优先(照度触发)：黄色 `#FF9500`
- 定时任务竖线：黑色粗线

**开关与回路控制抽屉（v1.1新增）**：
- 回路预览圆点（开）：`#34C759` 绿色
- 回路预览圆点（关）：透明背景 + 边框
- 已选回路边框：`#34C759` 绿色
- 已选回路背景：绿色半透明
- 模式卡片激活边框：`#007AFF` 蓝色
- 摘要区背景：蓝色半透明
