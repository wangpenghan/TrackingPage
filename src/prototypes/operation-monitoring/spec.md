# 作业盯控 (Operation Monitoring)

## 1. 简要概述
作业盯控页面用于车站综控室对列车在站作业的全流程监控。核心目标是保障作业的连续性和安全性，特别是针对有接续关系的列车（如折返车），通过合并显示来简化监控视图。页面提供实时的作业状态（检票、站台、出站、上水等）、人员派班管理以及异常预警功能。

## 2. 功能说明

### 2.1 核心概念：作业单元
表格的每一行代表一个"作业单元"，而非单纯的单趟列车。作业单元分为四类：
1. **途径车 (Through)**: 既有接车又有发车作业的同一趟列车。
2. **接续车 (Connected)**: 终到车 (Arrival) + 始发车 (Departure) 的组合。终到车到站后转换为始发车，两者需合并显示，共享股道/站台信息。
3. **始发车 (Origin)**: 从车库直接开出的始发车（无前序载客列车）。
4. **终到车 (Terminating)**: 到站后直接回库的终到车（无后序载客列车）。

### 2.2 列表字段与显示逻辑
列表按**图定到点**（或发点）排序。

| 字段模块 | 字段项 | 显示逻辑 |
|:---|:---|:---|
| **列车信息** | 车次 | 显示车次。接续车显示 "A123 / D456"（换行或并排）。 |
| | 类型 | 始发 / 终到 / 途径 / 接续 |
| | 接续关系 | 图标或文字标识接续状态。 |
| **时间信息** | 图定/实际到点 | 始发车显示 "--"。接续车显示终到车的到点。支持显示正晚点（红/绿）。 |
| | 图定/实际发点 | 终到车显示 "--"。接续车显示始发车的发点。 |
| **客流信息** | 上车 | 始发、途径、接续（后序车）显示。 |
| | 下车 | 终到、途径、接续（前序车）显示。 |
| | 换乘 | 途径、接续（前序车）显示。 |
| **车长信息** | 姓名/电话 | 接续车可能有两个车长，需分别展示（如 "张三(A123)... / 李四(D456)..."）。 |
| **位置信息** | 股道 | 全部显示。接续车一致。 |
| (可配置) | 站台 | 全部显示。接续车一致。 |
| | 检票口 | 始发、途径、接续（后序车）显示。终到车隐藏。 |
| | 出站口 | 终到、途径、接续（前序车）显示。始发车隐藏。 |
| **停靠信息** | 编组/位置/方向 | 接续车需分别显示前序和后序车的停靠信息（可能不同）。 |
| **临站信息** | 临站发车时间 | 显示上一站发车时间。 |
| **作业盯控** | 检票作业 | 显示人数 + 状态。 |
| | 站台作业 | 显示人数 + 状态。 |
| | 出站作业 | 显示人数 + 状态。 |
| | 上水吸污 | 显示人数 + 状态。 |
| **操作** | 备注 | 文本输入/弹窗。 |
| | 派班 | 手动调整作业人员。 |
| | 一键完成 | 标记该单元所有作业为完成。 |

### 2.3 作业状态逻辑
每个作业项（如检票）包含状态指示：
*   **正常 (Normal)**: 已打卡且时间正常。
*   **晚打卡 (Late)**: 已打卡但超时。表格状态显示"正常"，但详情/Tooltip中实际打卡时间标红。
*   **未打卡 (Missing)**: 超过规定时间未打卡。表格状态标红，并显示"人员派班提醒"。
*   **无需作业 (N/A)**: 例如始发车无出站作业。

### 2.4 交互功能
*   **显示设置**: 勾选显示/隐藏位置信息列（股道、站台、检票口、出站口），至少保留1个。
*   **手动派班**: 点击"派班"或异常状态，弹出人员选择框，重新指定作业人员。
*   **一键完成**: 快速结束所有作业流程。
*   **添加备注**: 记录特殊情况。

### 2.5 顶部信息栏
*   **时间显示**: 在页面顶部标题栏中间位置，实时显示当前系统日期和时间。
    *   日期格式: YYYY年MM月DD日
    *   时间格式: HH:mm:ss
    *   样式: 3D立体卡片风格，蓝字日期，黑字时间。
