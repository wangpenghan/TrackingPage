# 基本计划页面设计规格

## 📋 业务与功能

### 1.1 核心目标
基本计划页面用于展示铁路基本运行图信息，包含全路所有开行列车信息，通过图号区分。解决原有界面信息量太大、没有重点、布局杂乱的问题。

### 1.2 功能模块

- **图号选择器**：支持选择不同的基本运行图
- **智能搜索栏**：支持按图号、站名、车次进行数据检索
- **列车卡片列表**：以卡片形式展示列车信息，重点突出
- **开行规则可视化**：直观展示每日开行、隔日开行、周期开行三种开行规则
- **站详情时间轴**：以时间轴形式展示停靠站信息（非列表形式）
- **数据验证**：自动验证到达时间不能早于发车时间等规则

### 1.3 开行规则说明

| 规则类型 | 周期 | 说明 |
|---------|------|------|
| 每日开行 | 1 | 不考虑规律，每天运行 |
| 隔日开行 | 2 | 从指定日期开始，规律配置0表示第1天运行，1表示第1天不开 |
| 周期开行 | 自定义 | 自定义开行周期和开行规律，定义几天一个周期，在这个周期内的哪几天开行 |

## 📊 内容规划

### 2.1 信息架构

```
基本计划页面
├── 顶部工具栏
│   ├── 图号选择器
│   └── 搜索栏（图号/站名/车次）
├── 统计概览
│   ├── 总列数
│   ├── 高铁数量
│   ├── 普速数量
│   └── 开行类型分布
├── 列车列表区
│   ├── 筛选标签（全部/高铁/普速/始发/终到）
│   └── 列车卡片网格
│       ├── 车次卡片
│       ├── 开行规则徽章
│       ├── 始发/终到信息
│       └── 展开按钮
└── 站详情抽屉
    ├── 车次头部信息
    ├── 时间轴展示停靠站
    └── 数据验证提示
```

### 2.2 数据来源

- **数据类型**：基本运行图列车数据
- **数据源**：`mockBasicPlanTrains` 函数
- **关键字段**：
  - `id`: 列车唯一标识
  - `trainNo`: 车次号
  - `trainType`: 列车类型（高铁/普速）
  - `diagramNo`: 图号
  - `operationRule`: 开行规则（daily/alternate/custom）
  - `operationCycle`: 开行周期
  - `operationPattern`: 开行规律
  - `originStation`: 始发站
  - `destinationStation`: 终到站
  - `stations`: 停靠站列表
    - `stationName`: 站名
    - `stationOrder`: 站序
    - `arrivalTime`: 到达时间
    - `departureTime`: 发车时间

### 2.3 数据验证规则

1. **时间顺序验证**：到达时间不能早于发车时间
2. **站序排列**：按照站序排列
3. **始发站规则**：没有到达时间，发车时间最早
4. **终到站规则**：没有发车时间，到达时间最晚
5. **时间递增**：依次增加

## 🎨 布局与结构

### 3.1 整体布局

- **布局模式**：响应式卡片网格布局
- **容器宽度**：最小宽度 1200px
- **关键尺寸**：
  - 卡片宽度：320px
  - 卡片圆角：12px
  - 间距：16px
  - 抽屉宽度：600px

### 3.2 模块详细布局

**顶部工具栏**：
- 左侧：图号选择器（下拉菜单）
- 右侧：搜索栏（图标 + 输入框）

**统计概览**：
- 四个统计卡片横向排列
- 每个卡片：图标 + 数值 + 标签

**列车列表区**：
- 筛选标签：横向排列
- 列车卡片：网格布局，自适应列数

**站详情抽屉**：
- 时间轴垂直布局
- 每个站点：时间 + 站点 + 状态

## 🎨 视觉规范

### 4.1 设计规范来源

**本设计基于**：
- [x] macOS 统一风格样式
- [x] 大胆创新的设计理念

**说明**：参考 macOS 设计系统，采用简约、清晰、现代化的视觉风格。

### 4.2 自定义设计要点

**色彩规范（macOS 风格）**：
- 背景：`#F5F5F7`（浅色）/ `#1C1C1E`（深色）
- 卡片背景：`#FFFFFF`（浅色）/ `#2C2C2E`（深色）
- 主色调：`#007AFF`（浅色）/ `#0A84FF`（深色）
- 成功色：`#34C759`（浅色）/ `#30D158`（深色）
- 警告色：`#FF9500`（浅色）/ `#FF9F0A`（深色）
- 错误色：`#FF3B30`（浅色）/ `#FF453A`（深色）
- 边框：`#D2D2D7`（浅色）/ `#38383A`（深色）
- 文本主要：`#1D1D1F`（浅色）/ `#F5F5F7`（深色）
- 文本次要：`#86868B`（浅色）/ `#8E8E93`（深色）

**字体规范**：
- 标题字号：24px，字重 700
- 副标题字号：18px，字重 600
- 正文字号：14px，字重 400
- 小字字号：12px，字重 400

**间距规范**：
- 页面内边距：24px
- 模块间距：24px
- 卡片内边距：20px
- 元素间距：12px

**圆角规范**：
- 卡片圆角：12px
- 按钮圆角：8px
- 标签圆角：20px
- 输入框圆角：8px

**按钮风格**：
- 主按钮：高度 36px，背景 `#007AFF`，白色文字
- 次要按钮：高度 36px，背景透明，边框 1px，主色调文字

**开行规则可视化**：
- 每日开行：绿色标签 + 日历图标
- 隔日开行：橙色标签 + 交替图标
- 周期开行：蓝色标签 + 循环图标
