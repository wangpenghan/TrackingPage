### 一、基本图

#### 用户描述

> "计划生成的业务逻辑中，第一步是基本图，这个图包含全路的所有开行列车信息，通过图号区分，铁路每年多次调图，就是这个基本运行图他包含列车基本的开行信息和停靠站信息，缺少股道，站台等调度相关的信息。"
> 开行规则分为3种：1是每日开行，周期是1，不考规律。2是隔日开行，周期是2，规律需要配置从哪天开始，可以用0表示第1天运行，1表示第1天不开。周期开行需要自定义开行周期和开行规律，定义几天一个周期，在这个周期内的哪几天开行这是规律。定义好开行规则就能自动在日历上标记出来该车次的运行图。这个信息不应该是单纯的文字描述，应能直观体现出来。

#### 核心信息

| 项目 | 内容 |
|------|------|
| 名称 | 基本图 |
| 内容 | 全路所有开行列车信息 |
| 区分方式 | 通过图号区分 |
| 背景 | 铁路每年多次调图 |
| 包含信息 | 列车基本开行信息、停靠站信息 |
| 缺少信息 | 股道、站台等调度相关信息 |
