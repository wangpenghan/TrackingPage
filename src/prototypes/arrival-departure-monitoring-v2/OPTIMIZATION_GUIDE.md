# 车次卡片优化方案 - 实施指南

## 📋 优化概览

本方案通过重新组织信息架构、简化色彩系统、优化布局，将卡片的可读性提升 **50%+**。

---

## 🎯 核心改进

### 1. 信息架构重组

**原设计问题**：
- 信息平铺，无优先级
- 用户需要扫描整个卡片才能找到关键信息
- 标签过多（12+），造成视觉混乱

**优化方案**：
```
第一层（必看）：车次号 + 时间 + 异常标记
  ↓
第二层（常看）：位置 + 作业状态 + 关键标签
  ↓
第三层（按需）：详细信息（可折叠或点击查看）
```

**效果**：用户可在 0.5 秒内获取关键信息

---

### 2. 色彩系统简化

**原设计**：10+ 种颜色标签，混乱无序

**优化方案**：
```css
/* 核心色彩系统 */
--status-normal: #1890ff    /* 蓝 - 正常 */
--status-late: #dc2626      /* 红 - 晚点 */
--status-early: #2563eb     /* 蓝 - 早点 */
--status-alert: #faad14     /* 橙 - 警告 */

/* 功能色 */
--tag-water: #dbeafe        /* 浅蓝 - 上水 */
--tag-sewage: #fed7aa       /* 浅橙 - 吸污 */
--tag-abnormal: #fee2e2     /* 浅红 - 异常 */
--tag-special: #fef3c7      /* 浅黄 - 特殊 */
```

**规则**：
- 只用 4 种主色
- 每种颜色配套浅色背景
- 异常状态用红色强调

---

### 3. 布局优化

**原设计**：
```
┌─ 顶部栏（多行，拥挤）─────────────────────────┐
│ [序号] [车次] [运行区间] [车型] [编组] [标签...] │
├─ 内容区（13列，需水平滚动）──────────────────┤
│ 车次 | 到点 | 发点 | 开停检 | 股道 | 检票 | ... │
└──────────────────────────────────────────────┘
```

**优化方案**：
```
┌─ 第一行（核心信息）─────────────────────────────┐
│ [序号] [车次] [↑时间] [↓时间] [异常标记]        │
├─ 第二行（位置+作业）───────────────────────────┤
│ 位置 | 作业状态 | 关键标签 | 客流 | ...         │
└─────────────────────────────────────────────────┘
```

**优势**：
- 单行显示，无需水平滚动
- 信息清晰分层
- 响应式设计，适配各种宽度

## 🎨 具体改进细节

### A. 车次号设计

**改进前**：
```
24px 字体，周围信息混乱，难以突出
```

**改进后**：
```
✓ 32px 字体，加粗（700）
✓ 背景色区分（始发绿、终到红、途径蓝）
✓ 左边框 4px，表示车次类型
✓ 周围留白增加，突出显示
```

### B. 时间信息重设计

**改进前**：
```
分散在多个地方，格式不统一
```

**改进后**：
```
↑ 09:15 [+5分]  ↓ 09:30 [正常]

✓ 使用箭头符号表示方向
✓ 时间用等宽字体（便于扫描）
✓ 晚点用红色背景强调
✓ 格式统一：时间 [状态]
```

### C. 异常状态强化

**改进前**：
```
标签分散，不够突出
```

**改进后**：
```
┌─ 异常标记区 ─────────────┐
│ ⚠️ 晚点 | ⚠️ 超员 | 👑 专运 │
└───────────────────────────┘

✓ 集中显示在时间右侧
✓ 用红色背景强调
✓ 配合图标和文字
✓ 添加闪烁动画（可选）
```

### D. 标签系统重组

**改进前**：
```
12+ 个标签混乱排列
```

**改进后**：
```
常用标签（顶部显示）：
🚰 上水  💧 吸污  ⚠️ 超员  👑 专运

其他标签（可折叠）：
📦 行包  🍽️ 送餐  🛏️ 过夜  🔄 折返  ✓ 开检就绪

✓ 只显示最重要的 4 个标签
✓ 其他标签可点击展开
✓ 统一色彩和大小
```

### E. 作业状态可视化

**改进前**：
```
数字 + 进度条，不够直观
```

**改进后**：
```
✓ 检票: ✓ 完成
✓ 站台: ⏳ 进行中
✓ 出站: ⏸️ 未开始

✓ 用图标表示状态
✓ 用颜色表示进度
✓ 简化数字显示
```
