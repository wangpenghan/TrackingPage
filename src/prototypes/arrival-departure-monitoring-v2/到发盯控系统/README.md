# 到发盯控系统 - 独立应用

## 快速启动

### 方法一：双击启动（推荐）
直接双击 `启动到发盯控系统.bat` 文件，系统会自动打开浏览器运行应用。

### 方法二：手动打开
直接双击 `app.html` 文件，使用浏览器打开。

## 文件说明

| 文件 | 说明 |
|------|------|
| `app.html` | 应用入口文件，双击即可在浏览器中打开 |
| `app.jsx` | 应用主代码，包含所有组件和逻辑 |
| `启动到发盯控系统.bat` | Windows 批处理启动脚本 |
| `style.css` | 主样式文件 |
| `grid-style.css` | 网格布局样式 |
| `WaterSewageConfigDrawer.css` | 上水吸污配置抽屉样式 |

## 功能特性

- ✅ 列车列表展示（卡片式布局）
- ✅ 搜索过滤功能
- ✅ 深色/浅色模式切换
- ✅ 上水吸污配置抽屉
- ✅ 16编组车厢可视化配置
- ✅ 整列/单数/双数快速选择
- ✅ 实时统计信息

## 技术栈

- React 18 (CDN)
- Ant Design 5 (CDN)
- Lucide Icons (CDN)
- 纯前端实现，无需后端

## 浏览器要求

- Chrome 90+
- Edge 90+
- Firefox 90+
- Safari 14+

## 注意事项

1. 首次打开需要联网加载 CDN 资源
2. 建议使用现代浏览器获得最佳体验
3. 数据为模拟数据，刷新页面会重置
