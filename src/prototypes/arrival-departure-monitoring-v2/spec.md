# 到发盯控页面设计规格

## 📋 业务与功能

### 1.1 核心目标
到发盯控页面用于展示列车到发信息，提供作业监控、旅服信息、站车信息等功能模块。

### 1.2 功能模块

- **作业监控**：展示检票作业、站台作业、出站作业、结合部作业等作业详情
- **旅服信息**：展示列车旅服相关信息
- **站车信息**：展示站车交互信息
- **操作日志**：展示系统操作记录，点击日志图标可查看列车操作日志
- **客运记录**：展示遗失物品、重点旅客、交接班等客运业务记录

### 1.3 操作日志功能

- **入口**：表格最后一列"日志"列，点击日志图标打开
- **抽屉规格**：宽度 480px，与计划干预抽屉保持一致
- **展示内容**：
  - 操作时间
  - 操作人
  - 操作类型（修改/执行/确认/系统）
  - 操作内容
  - IP地址
- **日志类型**：
  - 修改：晚点时间调整等
  - 执行：进站开检等操作
  - 确认：上水作业完成确认等
  - 系统：自动触发的广播、闸机等

---

## 📊 作业详情抽屉

### 2.1 核心目标
作业详情抽屉用于展示列车的详细作业信息，包括检票口客运员、出站口客运员、上水员、站台客运员、站台值班员等作业类型的详细执行情况。

### 2.2 功能清单

- **作业监控表格**：展示所有作业类型的详细信息
  - 作业类型（检票口客运员、出站口客运员、上水员、站台客运员、站台值班员）
  - 姓名
  - 位置
  - 作业内容
  - 计划时间
  - 实际时间
  - 状态（已完成/未开始）
- **作业派班**：点击按钮弹出作业派班弹窗，支持选择作业和人员
- **触发方式**：双击作业信息卡片中的任意作业卡片打开抽屉

### 2.3 交互要点

- 双击检票作业、站台作业、出站作业、结合部作业卡片触发抽屉展开
- 点击遮罩层或关闭按钮关闭抽屉
- 支持深色/浅色模式切换
- 实际时间晚于计划时间时红色高亮显示

## 5. Axure API 规范

### 5.1 事件列表 (eventList)

| 事件名称 | 描述 | payload 类型 |
|---------|------|-------------|
| `on_train_select` | 选中列车时触发，传递列车ID | `string` |
| `on_station_change` | 切换车站时触发，传递车站名称 | `string` |
| `on_view_mode_change` | 视图模式切换时触发，传递模式名称 | `string` |
| `on_data_change` | 数据发生变化时触发 | `JSON string` |
| `on_filter_change` | 筛选条件变化时触发，传递筛选配置 | `JSON string` |

### 5.2 动作列表 (actionList)

| 动作名称 | 描述 | 参数类型 |
|---------|------|---------|
| `select_train` | 选中指定列车 | `string` (列车ID) |
| `switch_station` | 切换到指定车站 | `string` (车站名称) |
| `set_view_mode` | 设置视图模式 | `string` (normal/intervention) |
| `refresh_data` | 刷新数据 | - |
| `set_search_term` | 设置搜索关键词 | `string` |
| `toggle_dark_mode` | 切换深色模式 | - |
| `set_filters` | 设置筛选条件 | `JSON string` |

### 5.3 变量列表 (varList)

| 变量名称 | 描述 |
|---------|------|
| `selected_train_id` | 当前选中的列车ID |
| `current_station` | 当前显示的车站名称 |
| `view_mode` | 当前视图模式（normal/intervention） |
| `data_version` | 数据版本号，用于追踪数据变化 |
| `search_term` | 当前搜索关键词 |
| `dark_mode` | 是否启用深色模式 |
| `control_mode` | 控制模式（single/代管） |
| `simple_mode` | 是否启用简洁模式 |
| `train_count` | 当前显示列车数量 |

### 5.4 配置项列表 (configList)

| 配置项 | 类型 | 显示名称 | 默认值 | 说明 |
|-------|------|---------|-------|------|
| `currentStation` | select | 默认车站 | 重庆东 | 页面加载时默认显示的车站 |
| `darkMode` | checkbox | 深色模式 | false | 是否默认启用深色模式 |
| `simpleMode` | checkbox | 简洁模式 | false | 是否默认启用简洁模式 |
| `controlMode` | select | 控制模式 | 代管 | 车站控制模式 |
| `passengerFlowThreshold.boarding` | inputNumber | 大客流阈值-上车 | 500 | 上车人数超过此值标记为大客流 |
| `passengerFlowThreshold.alighting` | inputNumber | 大客流阈值-下车 | 500 | 下车人数超过此值标记为大客流 |
| `passengerFlowThreshold.transfer` | inputNumber | 大客流阈值-换乘 | 200 | 换乘人数超过此值标记为大客流 |

### 5.5 数据项列表 (dataList)

#### train_schedules - 列车时刻表数据

| 字段名 | 描述 |
|-------|------|
| `id` | 列车唯一标识 |
| `train_no` | 列车车次号 |
| `train_type` | 列车类型 |
| `status` | 列车状态 |
| `station` | 所属车站 |
| `arrival` | 到达信息 |
| `departure` | 发车信息 |

#### stations - 车站列表数据

| 字段名 | 描述 |
|-------|------|
| `id` | 车站ID |
| `name` | 车站名称 |
| `train_count` | 列车数量 |

## 📊 情景模式抽屉

### 10.1 核心目标

情景模式抽屉用于集中管理三种特殊运营模式：专运模式、应急模式、大面积晚点模式。当前阶段实现专运模式的完整功能。
