# 客运指挥

## 📋 业务与功能

### 1.1 核心目标
多站列车盯控系统，以可缩放平移的时间轴+卡片定位布局展示各站车次到发信息。卡片采用“磁悬浮车头”风格，顶部嵌入流线型列车浮雕与霓虹轨迹，通过分层玻璃材质突出核心信息（车次、方向、区间、到开点、股道、晚点），到站/离站双行排列，中间以 10px 高铁路枕木样式股道线分隔，时间重叠的车次自动错开成多层车道，终到/始发接续列车显示虚线连接线。

### 1.2 功能清单
- **时间轴**：顶部显示 06:00-24:00 小时/半小时刻度与当前时间指示器，支持缩放（Ctrl+滚轮/按钮）和水平拖拽平移
- **车次卡片定位**：卡片按到发时间在时间轴上定位，不换行，水平滚动，时间重叠的车次自动错开成多层
- **到站/离站双行布局**：每个站点内到站（终到）一行、离站（始发+途径）一行，中间 10px 高股道线
- **车次选择与关联**：点击卡片选中，同车次号关联高亮，**同站接续列车（connectedToId）** 也关联高亮，其余卡片淡化
- **接续列车连接线**：终到列车与接续始发列车之间显示虚线渐变连接线
- **深色/浅色模式切换**：支持 macOS 风格双主题
- **缩放控制**：工具栏缩放按钮 + Ctrl+滚轮缩放，缩放范围 2x-20x

### 1.3 交互要点
- **时间轴缩放**：Ctrl+滚轮 或 工具栏 +/- 按钮，以鼠标位置为中心缩放
- **时间轴平移**：鼠标拖拽内容区域水平平移，时间轴与内容区同步滚动
- **卡片点击**：选中车次 → 同号关联高亮 + 接续列车关联高亮 → 其余淡化 → 点击空白取消
- **卡片悬停**：微上浮 3px + 阴影增强
- **主题切换**：深色/浅色一键切换，过渡动画 500ms

## 🎨 布局与结构

### 3.1 整体布局
- **布局模式**：时间轴+内容区双区域同步滚动
- **内容区宽度**：由缩放级别决定 = (END_HOUR - START_HOUR) × 60 × pixelsPerMinute
- **关键尺寸**：
  - 顶部导航栏：h-12
  - 时间轴：h-9
  - 车次卡片：w-260px，h-88px
  - 到站/离站行高：自适应，最小156px，根据车道数动态增加（`CARD_HEIGHT + (maxLanes + 1) × 22`）
  - 股道线高度：10px（上下轨线 + 竖枕木重复图案）
  - 站点总高度：arrRowHeight + 10 + depRowHeight（动态计算）
  - 缩放范围：2x ~ 20x（pixelsPerMinute）
  - 车道间距：最大 30px 或均匀分配可用空间

### 3.2 碰撞错开规则
1. 按时间顺序排列所有卡片
2. 依次分配车道：选择第一个可用的、不与该卡片重叠的车道
3. 重叠判断：`existingCard.leftPx + CARD_WIDTH > currentCard.leftPx - 8px`
4. 可用车道间距：`LANE_GAP = 30px`
5. 车道垂直居中：`getCardTop(lane, maxLanes+1, rowH, cardH)`

### 3.3 卡片定位规则
- **终到列车**：卡片中心对齐到达时间位置
- **始发列车**：卡片中心对齐发车时间位置
- **途径列车**：卡片中心对齐发车时间位置（离站行）
- **定位公式**：leftPx = (timeMinutes - START_HOUR × 60) × pixelsPerMinute - CARD_WIDTH / 2

### 3.4 同步滚动机制
- 时间轴和内容区共享 scrollLeft
- 内容区 onScroll → 同步时间轴 scrollLeft
- 拖拽平移 → 同时设置两个容器 scrollLeft
- 缩放时以鼠标位置为中心重新计算 scrollLeft

### 4.3 卡片形状与风格
- **核心形状**: 采用顶部半圆车头 + 底部圆角矩形的整体胶囊造型。
  - 顶部 40px 区域为半圆车头：`border-radius: 50% 50% 0 0`
  - 底部主体为圆角矩形：`border-radius: 0 0 16px 16px`
  - 整体卡片：`border-radius: 16px`
- **背景质感**:
  - **主体层**：浅色 `linear-gradient(145deg, #FBFCFE, #F3F6FA, #EEF2F7)`，深色 `linear-gradient(145deg, #3A3A3C, #2C2C2E, #1C1C1E)`
  - **错误态**：浅色 `linear-gradient(145deg, #FFF5F5, #FEF0F0)`，深色 `linear-gradient(145deg, #3A2A2A, #2C2222)`
  - **装饰线**：车头底部中央有一条渐变装饰线，颜色与停站类型关联
- **边框与装饰**:
  - **主边框**：单层描边，颜色与停站类型关联，选中时高亮
  - **重点标记**：底部一排彩色圆角标签，显示0~5个重点服务标记（上水/吸污/行包/快运/送餐/出库/入库），每个标记包含图标和状态值0-5
  - **状态指示**：晚点标签显示在时间旁，红色高亮

**股道线（到站/离站行之间）**：
- 高度 10px，全宽
- 底部重复枕木图案：repeating-linear-gradient 2px 宽竖线，间隔 11px
- 上下各一条水平轨线，两端渐变淡出

**接续列车连接线**：
- SVG 曲线，从终到卡片底部中心到离站卡片顶部中心
- 使用 `connectedToId` 属性匹配
- 线性渐变（主色 80% → 主色 40%）
- 虚线样式（stroke-dasharray 4 3），strokeWidth 2

**晚点标签**：
- 浅色模式：红底 #fee2e2 + 红色边框 #ef4444 + 红色文字 #dc2626
- 深色模式：红底 #3f1e1e + 红色半透明边框 #dc2626 + 红色文字 #fb7185
- 仅晚点车次显示，无晚点不标注

**时间网格**：
- 小时线：浅色半透明竖线
- 半小时线：更浅半透明竖线
- 当前时间线：红色半透明竖线 + 红色脉冲圆点

**卡片状态**：
- 默认：暖灰渐变背景 + 细边框 `rgba(148,163,184,0.25)` + 轻阴影 `0 2px 10px rgba(100,116,139,0.1)`
- 错误：玫瑰红背景 + 红色边框 `#E11D48` + 低强度脉冲光晕（2s 周期）
- 选中：停站类型色边框 `1.5px` + 同色光晕 `0 6px 24px rgba(...,0.18)`
- 关联：绿色边框 `#34C759`（浅色）/ `#30D158`（深色）+ 绿色光晕
- 淡化：opacity 0.35 + blur 2px

### 4.3 组件状态
- **默认态（default）**：玻璃态背景，细边框，微阴影
- **悬停态（hover）**：上浮 3px，阴影增强
- **选中态（selected）**：天蓝色边框 + 蓝色光晕 (glow + ring)
- **关联态（linked）**：绿色边框 + 绿色光晕（含同车次号 + 接续列车）
- **错误态（error）**：红色调背景 + 红色边框 + 红色微光晕
- **淡化态（dimmed）**：低透明度 0.25 + 微模糊
