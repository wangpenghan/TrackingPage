# 代管盯控

## 📋 业务与功能

### 1.1 核心目标
代管盯控页面用于同时监控多个代管车站的列车到发情况。与单站到发盯控不同，代管盯控需要：
- 以时间轴为核心展示多个车站的列车运行状态
- 支持同车次跨多个车站的虚线连接展示
- 提供灵活的车站配置和面板分组功能
- 直观展示接续关系、早晚点、股道变更等关键信息

### 1.2 功能清单

**配置模块（首次启动）**
- **[P0]** 车站信息管理：手动录入代管车站列表，支持拖拽排序
- **[P0]** 车站配置：股道范围、上下行方向、正倒序、候车室、检票口、出站口、车型（高铁/普速）筛选
- **[P0]** 面板配置：支持将车站拆分为多个面板，自定义面板名称和股道范围
- **[P0]** 显示配置：配置车次卡片上显示的可选内容（站台、列车长1、列车长2、客流、重点事项）
- **[P0]** 提醒配置：临站发车提醒、出务预告提醒、前方站选择、重新派班时间范围配置

**展示模块**
- **[P0]** 时间轴：可左右拖动，默认显示当前时间范围，根据车密度动态调整刻度（5分钟/30分钟）
- **[P0]** 当前时间标记：贯穿所有盯控面板的垂直时间线
- **[P0]** 盯控面板：按配置加载满足条件的车次，以卡片形式展示
- **[P0]** 车次卡片：显示车次、到站时间、离站时间、股道、站停时间（用时长线表示）
- **[P0]** 方向标识：车次卡片体现进出站方向（南/北）
- **[P0]** 接续关系：标记终到接续始发车的关系，同股道连续车次展示
- **[P0]** 虚线连接：相同车次跨多个车站的虚线连接，点击后突出显示
- **[P0]** 异常标记：早晚点时间、股道变化情况标记
- **[P1]** 车次详情：点击车次弹出操作面板（复用现有到发盯控功能）

**交互模块**
- **[P0]** 主题切换：支持深色/浅色模式切换，深色模式提高对比度
- **[P0]** 时间轴缩放：根据车次密度自动/手动调整时间刻度
- **[P1]** 卡片悬停：显示更多信息（车长、客流、重点事项）
- **[P1]** 快速筛选：按异常、正在作业等条件筛选

### 1.3 交互要点

- **时间轴拖动**：鼠标拖拽左右移动时间轴，滚轮缩放时间范围
- **车次卡片点击**：弹出操作面板，功能同到发盯控
- **同车次虚线点击**：高亮显示该车次在所有车站的连接线
- **卡片悬停**：显示完整信息浮层
- **配置入口**：顶部工具栏提供配置按钮，首次启动自动弹出配置向导

## 📊 内容规划

```
代管盯控
├── 顶部工具栏
│   ├── 页面标题
│   ├── 时间轴控制（缩放、当前时间）

    ├── 面板1（如：重庆东1-8股道）
    │   ├── 面板标题

```

### 2.2 数据来源

- **数据类型**：列表型数据（车次时刻表）
- **数据源**：生成示例数据（模拟多车站车次数据）
- **关键字段**：
  - `trainNo`: 车次号
  - `station`: 车站名称
  - `arrivalTime`: 到站时间
  - `departureTime`: 离站时间
  - `track`: 股道
  - `direction`: 方向（上行/下行）
  - `trainType`: 车型（高铁/普速）
  - `isOrigin`: 是否始发车
  - `isEnd`: 是否终到车
  - `connectionTrainNo`: 接续车次号
  - `lateEarly`: 早晚点时间
  - `trackChange`: 股道变更信息
  - `master1`, `master2`: 列车长信息
  - `passengerFlow`: 客流信息
  - `keyItems`: 重点事项（上水、吸污、行包等）

### 2.3 内容示例

**车次卡片示例**：
- 车次：G8888
- 时间：17:00/17:30（到站/离站）
- 股道：5
- 站停时间：用时间线长度表示30分钟
- 方向：箭头标识（南→北或北→南）

**面板示例**：
- 面板名称：重庆东1-8股道
- 包含车次：按到站时间排序的所有经过1-8股道的车次

## 🎨 布局与结构

### 3.1 整体布局

- **布局模式**：垂直分层布局
- **容器宽度**：流式布局，占满视口
- **关键尺寸**：
  - 顶部工具栏：高度56px
  - 时间轴区域：高度60px
  - 盯控面板：垂直排列，每个面板最小高度200px
  - 车次卡片：高度根据内容自适应，最小间距5px
  - 面板间距：16px

### 3.2 响应式适配

- **桌面端（≥1400px）**：多面板并排展示（最多3列）
- **平板端（768-1399px）**：面板垂直堆叠
- **移动端（<768px）**：简化展示，仅显示关键信息

## 📐 布局详细设计

### 6.1 时间轴设计

```
┌─────────────────────────────────────────────────────────────┐
│  ←  │  16:00  │  16:05  │  16:10  │  16:15  │  16:20  │  →  │
├─────┴─────────┴─────────┴─────────┴─────────┴─────────┴─────┤
│                              │                              │
│                              │  ← 当前时间标记线（红色）       │
│                              │                              │
└──────────────────────────────┼──────────────────────────────┘
                               │
```

**刻度规则**：
- 车次密集时（>10列/小时）：5分钟刻度
- 车次稀疏时（≤10列/小时）：30分钟刻度
- 支持手动缩放调整

### 6.2 车次卡片设计

```
┌─────────────────────────────────────┐
│ G8888  ▲  │  17:00  │  17:30  │  5  │
│           │  到站   │  离站   │股道 │
├───────────┴─────────┴─────────┴─────┤
│ ▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓ │  ← 站停时间线
└─────────────────────────────────────┘
```

**卡片内容规则**：
- 始发车：只显示离站时间
- 终到车：只显示到站时间
- 方向箭头：▲ 表示从南向北，▼ 表示从北向南
- 站停时间：用进度条长度表示，30分钟=100%宽度

### 6.3 同车次连接设计（参考图2）

```
面板1（重庆东）          面板2（巴南）           面板3（南川北）
    │                       │                       │
    │  ┌─────────┐          │                       │
    └──┤ G8888   ├──────────┤                       │
       └─────────┘          │  ┌─────────┐          │
                            └──┤ G8888   ├──────────┤
                               └─────────┘          │  ┌─────────┐
                                                    └──┤ G8888   │
                                                       └─────────┘
```

**连接规则**：
- 使用虚线直线连接（点到点直连，非曲线）
- 默认状态：灰色虚线，透明度50%
- 点击后：蓝色实线，透明度100%，加粗
- 连接点：卡片中心点

### 6.4 接续关系设计

```
同一面板内：
┌─────────┐      ┌─────────┐
│ G8888   │──────│ D1001   │
│ 终到    │ 接续 │ 始发    │
└─────────┘      └─────────┘
```

**接续标记规则**：
- 同股道连续车次用实线连接
- 接续时间显示在线条上方
- 站停时间用不同长度的时间线区分
