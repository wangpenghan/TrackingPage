# 客运模板页面设计规格

## 📋 业务与功能

### 1.1 核心目标

客运模板页面用于管理车次的完整生命周期，从车次启用、日常调度变更、调图批量变更，到最终停运，形成一个连续迭代的闭环流程系统。解决原有界面信息量太大、没有重点、布局杂乱的问题。

### 1.2 核心概念

| 概念 | 说明 |
|------|------|
| **生命周期** | 车次从启用到停运的完整过程，可能跨越多个调图周期 |
| **调图** | 大批量运行图变更（节假日、寒暑假），实质是大型调度命令 |
| **日常调度** | 对个别车的区间、时间、上水、吸污作业等调整 |
| **版本迭代** | 每次变更都是一个新版本，保留完整历史记录 |

### 1.3 功能模块

- **车次列表视图**：卡片式/表格式布局，展示所有车次当前状态
- **顶部信息区**：车次基础信息、编组信息、车型、股道、定员、地标、有效期等标签化展示
- **作业位置配置**：站台、检票口、候车室、出站口等位置信息，支持规则配置
- **时间配置**：基于到点/发点的4类时间规则（进站开检、进站停检、出站开检、出站停检），包含基准、偏移量、实际时间
- **停靠信息配置**：车型图形化展示、停车位、进站方向、出站方向等信息
- **运行配置**：运行类型、运行周期、运行规律，整合日历视图展示
- **关联模板管理**：广播模板（已实现）、开检/上屏/作业排班模板（预留）
- **编辑配置**：完整的编辑抽屉，包含所有字段分组

## 📊 内容规划

### 2.1 信息架构

```
客运模板页面
├── 顶部工具栏
│   ├── 车站选择器
│   ├── 搜索栏（车次/车型）
│   ├── 筛选器（列车类型、有效性、排序）
│   ├── 批量操作按钮
│   └── 导入/导出/新增按钮
├── 左侧：车次列表区
│   ├── 视图切换（卡片/表格）
│   ├── 筛选标签（全部/已启用/运行中/变更中）
│   ├── 车次卡片网格/表格
│   ├── 状态标识
│   └── 选中状态
└── 右侧：车次详情面板
    ├── 图号展示
    ├── 车次头部信息卡片
    │   ├── 车次号、类型、状态
    │   ├── 版本、启用日期、来源
    │   └── 信息标签行（编组+地标、车型、股道、定员）
    ├── 时间配置分组
    │   ├── 核心时间（到点、发点）
    │   ├── 进站开检规则
    │   ├── 进站停检规则
    │   ├── 出站开检规则
    │   └── 出站停检规则
    ├── 作业位置分组
    ├── 停靠信息分组
    │   ├── 站台平面图（上下两根线表示）
    │   ├── 停车线在站台两根线中间
    │   ├── 左右停车位标记（离站台两端向内30px）
    │   ├── 停车线和停车标记（标注"停"字，停靠侧绿色，另一侧灰色）
    │   ├── 8编组列车长度为停车线距离的一半，16编组长度为100%
    │   ├── 车厢样式：车头蓝色背景，其他车厢灰色背景黑色字体
    │   ├── 对齐规则：停靠左侧时车头左侧对齐停车线，停靠右侧时车头右侧对齐停车线
    │   └── 车头判断：根据编组方向判断是1车还是最后一节车厢
    ├── 运行配置分组
    │   └── 日历视图
    ├── 关联模板分组
    └── 编辑配置按钮
```

### 2.2 编辑配置字段分组

**基础配置**：
- 车站
- 车次类型
- 是否同步
- 到达车次
- 出发车次
- 始发车次
- 始发站
- 终到站

**时间配置**：
- 开检时间基准
- 开检停检基准
- 开检时间偏移
- 停检时间偏移
- 结束检票偏移
- 始发发车时间
- 终到到达时间

**车辆配置**：
- 列车车型
- 列车编组
- 停车位
- 进站方向
- 出站方向
- 编组方向
- 车次模式

**位置配置**：
- 股道
- 检票口（多选）
- 候车室（多选）
- 出站口（多选）

**有效期配置**：
- 起始有效期
- 终止有效期（带"当天"按钮）
- 是否有效

**运行配置**：
- 运行类型（带"设置"按钮）
- 运行周期
- 运行规律（带"预览"按钮）
- 正倒序维护
- 车型维护
- 股道维护

**扩展信息**：
- 担当局
- 列车等级
- 列车车底

**距离配置**：
- 始发站距离到站天数
- 终到站距离到站天数
- 基本图号

### 2.3 数据来源

- **数据类型**：客运模板车次生命周期数据
- **数据源**：`mockPassengerTemplateTrains` 函数
- **关键字段**：
  - `id`: 车次唯一标识
  - `trainNo`: 车次号
  - `trainType`: 列车类型（高铁/普速）
  - `trainTypeDetail`: 车次类型（origin/始发, passing/途经, terminal/终到）
  - `source`: 来源（basic/基本图, ticket/客票日计划, dispatch/调度日计划, manual/手动添加）
  - `status`: 状态（enabled/启用, running/运行中, changed/变更中, disabled/停运）
  - `currentVersion`: 当前版本号
  - `lifecycle`: 生命周期记录数组
  - `basicInfo`: 基本信息
    - `model`: 车型
    - `formationCount`: 编组数
    - `formationDirection`: 编组方向
    - `track`: 股道
    - `direction`: 上下行
  - `operationRules`: 作业规则
    - `operationCycle`: 运行周期
    - `orderMaintenance`: 正倒序维护
    - `modelMaintenance`: 车型维护
    - `trackMaintenance`: 股道维护
  - `relatedPlans`: 关联计划
    - `checkInPlan`: 开检计划
    - `screenPlan`: 上屏计划
    - `broadcastPlan`: 广播计划
    - `schedulePlan`: 作业排班计划
  - `editConfig`: 编辑配置
    - 所有编辑配置字段

### 2.4 变更类型

| 类型 | 说明 | 颜色标识 |
|------|------|----------|
| enable | 车次启用 | 绿色 |
| daily | 日常调度 | 蓝色 |
| diagram | 调图批量变更 | 橙色 |
| disable | 车次停运 | 红色 |

## 🎨 布局与结构

### 3.1 整体布局

- **布局模式**：两栏式响应式布局
- **容器宽度**：最小宽度 1400px
- **关键尺寸**：
  - 左侧列表宽度：420px
  - 右侧详情宽度：剩余空间
  - 卡片圆角：12px
  - 间距：16px

### 3.2 模块详细布局

**顶部工具栏**：
- 左侧：标题 + 副标题
- 中间：车站选择器 + 搜索栏 + 筛选器 + 查询按钮
- 右侧：批量操作 + 导入/导出 + 新增按钮

**左侧车次列表区**：
- 顶部：视图切换（卡片/表格）
- 筛选标签：横向排列
- 列表：车次卡片网格或表格，垂直滚动
- 表格：最小宽度 1400px，表头固定，斑马纹

**右侧车次详情面板**：
- 分区展示：按新分组展示所有信息
- 运行时间模块：左右分栏（320px 信息面板 + 日历）
- 编辑按钮：打开编辑抽屉

## 🎨 视觉规范

### 4.1 设计规范来源

**本设计基于**：
- [x] 简化的设计风格（去掉过度的 macOS 设计元素）
- [x] 保留 macOS 配色方案
- [x] 清晰的信息层次

**说明**：简化设计，去掉毛玻璃效果、复杂渐变、过度动画等，保留配色方案，采用简约、清晰、现代化的视觉风格。

### 4.2 色彩系统

**主色调**：
- 主色：`#0071E3`（蓝色）
- 成功色：`#34C759`（绿色）
- 警告色：`#FF9F0A`（橙色）
- 错误色：`#FF3B30`（红色）
- 紫色：`#AF52DE`

**背景色**：
- 页面背景：`#F5F5F7`
- 卡片背景：`#FFFFFF`
- 表面背景：`#F8F9FB`

**文字色**：
- 主要：`#1D1D1F`
- 次要：`#6E6E73`
- 三级：`#A1A1A6`

**边框色**：
- 轻边框：`rgba(0, 0, 0, 0.06)`
- 标准边框：`rgba(0, 0, 0, 0.1)`

**柔和背景色**：
- 主色柔和：`rgba(0, 113, 227, 0.08)`
- 成功色柔和：`rgba(52, 199, 89, 0.1)`
- 警告色柔和：`rgba(255, 159, 10, 0.1)`
- 错误色柔和：`rgba(255, 59, 48, 0.1)`
- 紫色柔和：`rgba(175, 82, 222, 0.1)`

### 4.3 圆角与阴影系统

**圆角系统**：
- 小圆角：`6px`
- 中圆角：`10px`
- 大圆角：`12px`
- 完全圆角：`9999px`

**阴影系统**：
- 小阴影：`0 1px 3px rgba(0, 0, 0, 0.06)`
- 中等阴影：`0 4px 12px rgba(0, 0, 0, 0.08)`

### 4.4 字体规范

- 字体栈：`-apple-system, BlinkMacSystemFont, 'Segoe UI', Roboto, sans-serif`
- 主标题字号：18px，字重 700
- 副标题字号：16px，字重 600
- 正文字号：14px，字重 400
- 小字字号：12px，字重 500

### 4.5 筛选标签样式

- 横向排列，间距 6px
- 未激活：灰色文字，透明背景
- 激活：蓝色背景，白色文字
- 圆角：`8px`
- 过渡：`200ms`

### 4.6 表格样式

- 最小宽度：1400px
- 表头：固定，灰色背景
- 斑马纹：奇数行浅灰色背景
- 选中：蓝色柔和背景
- 第一列（复选框）：sticky 定位，z-index: 2
- 边框：轻边框

### 4.7 运行时间模块样式

**左右分栏布局**：
- 左侧信息面板：320px 固定宽度
- 右侧日历：自适应宽度
- 间距：24px

**左侧信息面板**：
- 始发/终到信息：24px 大号时间，14px 站点名称
- 运行周期卡片：灰色背景，中圆角，边框
- 星期选择器：flex 布局，选中周一高亮蓝色
- 基本图号：16px，字重 600

**右侧日历**：
- 头部：月份标题 + 左右箭头 + "今天"按钮
- 日期格子：48px 高度
- 运行日：蓝色背景，白色文字
- 图例：非有效期/有效期内/已执行/未执行
