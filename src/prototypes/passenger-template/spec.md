# 客运模板页面设计规格

## 📋 业务与功能

### 1.1 核心目标

客运模板页面用于管理车次的完整生命周期，从车次启用、日常调度变更、调图批量变更，到最终停运，形成一个连续迭代的闭环流程系统。解决原有界面信息量太大、没有重点、布局杂乱的问题。

### 1.2 核心概念

| 概念 | 说明 |
|------|------|
| **生命周期** | 车次从启用到停运的完整过程，可能跨越多个调图周期 |
| **调图** | 大批量运行图变更（节假日、寒暑假），实质是大型调度命令 |
| **日常调度** | 对个别车的区间、时间、上水、吸污作业等调整 |
| **版本迭代** | 每次变更都是一个新版本，保留完整历史记录 |

### 1.3 功能模块

- **车次列表视图**：卡片式布局，展示所有车次当前状态
- **生命周期时间轴**：选中车次后，展示从启用到停运的完整时间线
- **变更对比视图**：对比相邻版本的差异
- **车次基本信息配置**：车型、编组、股道等基础信息
- **作业规则配置**：运行周期、正倒序维护、车型维护、股道维护
- **关联计划管理**：开检计划、上屏计划、广播计划、作业排班计划
- **自动关联规则配置**：基于车型、编组数、编组方向、站停时间、上下行的自动匹配
- **动态干预记录**：日常调度和调图变更记录

## 📊 内容规划

### 2.1 信息架构

```
客运模板页面
├── 顶部工具栏
│   ├── 车站选择器
│   ├── 图号选择器
│   ├── 搜索栏（车次/站名）
│   └── 视图切换（列表/时间轴）
├── 左侧：车次列表区
│   ├── 筛选标签（全部/运行中/已停运/高铁/普速）
│   └── 车次卡片网格
│       ├── 车次卡片
│       ├── 状态标识（启用/运行中/变更中/停运）
│       ├── 生命周期概览
│       └── 选中状态
├── 中间：车次详情面板
│   ├── 基本信息（车型、编组、股道、方向等）
│   ├── 作业规则配置
│   ├── 关联计划（开检、上屏、广播、排班）
```

### 2.2 数据来源

- **数据类型**：客运模板车次生命周期数据
- **数据源**：`mockPassengerTemplateTrains` 函数
- **关键字段**：
  - `id`: 车次唯一标识
  - `trainNo`: 车次号
  - `trainType`: 列车类型（高铁/普速）
  - `trainTypeDetail`: 车次类型（origin/始发, passing/途经, terminal/终到）
  - `source`: 来源（basic/基本图, ticket/客票日计划, dispatch/调度日计划, manual/手动添加）
  - `status`: 状态（enabled/启用, running/运行中, changed/变更中, disabled/停运）
  - `currentVersion`: 当前版本号
  - `lifecycle`: 生命周期记录数组
    - `version`: 版本号
    - `date`: 日期
    - `type`: 变更类型（enable/daily/diagram/disable）
    - `description`: 变更描述
    - `changes`: 变更详情
  - `basicInfo`: 基本信息
    - `model`: 车型
    - `formationCount`: 编组数
    - `formationDirection`: 编组方向
    - `track`: 股道
    - `direction`: 上下行
  - `operationRules`: 作业规则
    - `operationCycle`: 运行周期
    - `orderMaintenance`: 正倒序维护
    - `modelMaintenance`: 车型维护
    - `trackMaintenance`: 股道维护
  - `relatedPlans`: 关联计划
    - `checkInPlan`: 开检计划
    - `screenPlan`: 上屏计划
    - `broadcastPlan`: 广播计划
    - `schedulePlan`: 作业排班计划
  - `autoMatchRules`: 自动关联规则
    - `model`: 车型规则
    - `formationCount`: 编组数规则
    - `formationDirection`: 编组方向规则
    - `stopTime`: 站停时间规则
    - `direction`: 上下行规则
  - `editConfig`: 编辑配置
    - `station`: 车站
    - `trainType`: 列车类型
    - `isSync`: 是否同步
    - `arrivalTrainNo`: 到达车次
    - `departureTrainNo`: 出发车次
    - `originTrainNo`: 原始车次
    - `originStation`: 始发站
    - `terminalStation`: 终到站
    - `checkInTime基准`: 开检时间基准
    - `checkInStopTime基准`: 开检停时基准
    - `checkInTimeOffset`: 开检时间偏移
    - `checkInStopTimeOffset`: 开检停时偏移
    - `checkOutTimeOffset`: 开检出站时间偏移
    - `trainModel`: 车型
    - `trainFormation`: 编组
    - `parkingPosition`: 停车位置
    - `inboundDirection`: 入库方向
  - `stations`: 车站信息
    - `station`: 车站名称
    - `arrivalTime`: 到达时间
    - `departureTime`: 出发时间
    - `stopTime`: 停时
    - `platform`: 站台
    - `track`: 股道

### 2.3 变更类型

| 类型 | 说明 | 颜色标识 |
|------|------|----------|
| enable | 车次启用 | 绿色 |
| daily | 日常调度 | 蓝色 |
| diagram | 调图批量变更 | 橙色 |
| disable | 车次停运 | 红色 |

## 🎨 布局与结构

### 3.1 整体布局

- **布局模式**：三栏式响应式布局
- **容器宽度**：最小宽度 1400px
- **关键尺寸**：
  - 左侧列表宽度：320px
  - 中间详情宽度：480px
  - 右侧时间轴宽度：剩余空间
  - 卡片圆角：12px
  - 间距：16px

### 3.2 模块详细布局

**顶部工具栏**：
- 左侧：车站选择器 + 图号选择器
- 中间：搜索栏（图标 + 输入框）
- 右侧：视图切换按钮

**左侧车次列表区**：
- 顶部：筛选标签（横向排列）
- 列表：车次卡片网格，垂直滚动
- 卡片：车次号 + 状态标识 + 生命周期概览

**中间车次详情面板**：
- 分区展示：基本信息、作业规则、关联计划、自动关联规则
- 每个分区：标题 + 内容 + 编辑按钮
- 底部：保存/取消按钮

**右侧生命周期时间轴面板**：
- 时间轴：垂直布局，带连接线
- 版本节点：圆形图标 + 日期 + 变更类型
- 变更对比：左右分栏对比
- 版本详情：展开/折叠
